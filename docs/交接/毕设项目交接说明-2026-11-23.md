## 1. 研究主合同

未来五个市场交易日原始收益复利，**不扣大盘、行业或因子**。四档`R5≥0 / -5%<R5<0 / -10%<R5≤-5% / R5≤-10%`共同输出亏损/5%/10%概率。预测起点2017-01-03—2024-07-24，结果输入至07-31；历史2015—2016用于输入，不设252回归及252完成残差的预热门槛。

先以t时可知身份建立总体，再左连结果。当前源只能维护`OBSERVED_UNVERIFIED`观察总体，不是全历史上市A股。未知结果不填0，短历史、当前缺值、交易状态与监督掩码分离。收益口径、上市总体和终端价值未认证，正式训练保持关闭。

低风险估计不是“保证没有风险”。股票随市场/行业大跌是主任务正例，低分则是漏报；普通小损失虽非5%尾部事件仍不等于无风险。周内回撤和交易可执行性不等于五日持有端点。

## 3. 模型与公平评价

市场32/行业32/股票64掩码GRU形成128维价格上下文；共同背景按日期/行业去重编码。上下文query选择冻结公告正文和预测字段。正文可用、JSON合法、证据命中和语义正确分开；不使用LLM自报置信度或测试人工答案作质量特征。接受的完整股东版本连接价格+可用事件消息，去掉接收公司自身；独享机构无跨公司消息。

三专家四档softmax，`u=M Q exp(-softplus(λ)A) sigmoid(G)`；`g=1-(1-u_e)(1-u_g)`，辅助按u比例分享g，其余给价格专家。原始概率权重非负、和1、辅助权重≤u，全缺失回同模型价格专家；新鲜强事件不受旧±1 logit帽。g不是独立事件联合概率，最终温度后的影响界与原始界不混用。主训练混合NLL及匹配模态dropout/正则，不沿旧0.2/0.1辅助BCE。

四测试折2021/2022/2023/2024部分年，五种子42/2024/7/123/3407。每验证年前1—8月selection、9—12月calibration，所有阶段按实际结果结束日严格purge。主AP≥5%损失、四档NLL、Brier/校准、绝对告警召回/FNR/误报；每日Top10%仅容量参照。市场/行业mean(p5)是预期损失成员占比，不是指数跌幅概率；未知实际广度给界限。整市场日期配对**重叠移动块**20日主、5/60敏感、1000次；先每种子指标，再种子均值、四折等权，不偷换概率集成。

核心控制按新结构关闭市场/行业及其显式派生、事件、关系、质量、全部年龄、上下文注意力、保持度数/行业组成的随机关系。原生/预测字段和匿名文本另检。旧固定11项/420运行数退出；正式预算需真实数据/设备短跑。
