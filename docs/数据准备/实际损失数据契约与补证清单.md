# 实际损失任务：数据契约与RESSET补证清单

题目：基于多维时序数据融合的短期证券市场风险预测。更新：2026-11-26。

## 1. 主任务已经重定，不再扣除共同下跌

预测收盘日t之后五个**市场交易日**的累计持有期收益：`R5=∏(1+Dret)-1`。市场、行业或公司原因造成的实际损失都计入。四档为：R5≥0；-5%<R5<0；-10%<R5≤-5%；R5≤-10%。输出普通亏损概率、至少5%亏损概率及至少10%亏损概率。

主概率是未来五日达到5%损失阈值的估计，不是“下一周保证没有风险”。普通亏损、周内回撤、不可交易及模型误差仍可能发生。端点持有期收益不是日内最大回撤或可执行清算收益。

数据认证未完成时，程序可按原导出数值生成**候选**收益和标签，不把结果称作已认证全市场总回报。Dret/Daret、分红、复权、停牌及收益单位须正式说明。

### 新发现：大盘收益不是任取一条就能用

真实价格窗口验收扫描全部9,091,641源行，对所需61个历史日期逐日期核对`market_return_float`：所有61天都存在不同证券行之间的数值差异，共111,758条不一致比较，数值本身无缺失/非法。

这只证明该字段**不能无条件按日期压成一条市场收益**，不证明源表错误，也没有确认差异原因。它可能对应不同证券市场口径，需正式字段说明和市场标志匹配。程序没有取平均、随便选一行或用Rmrf冒充市场收益；当前真实小范围价格验证将市场掩码设0，行业未知也掩码，不能称完整市场/行业装配通过。该检查是61天子集，不夸称全2329日期每一天均已核对。

## 3. 优先补这些资料

**数据范围不延长：**当前研究预测2017年至2024-07-24，日收益结果输入到2024-07-31。日行情/交易/估值取2015-01-05—2024-07-31，包含已退市、非存续证券。身份/上市/行业历史还需取得在2015起点之前已经生效的基准，不只取期间内“发生变更”的记录。

### P0：正式词典和口径说明

先给PDF、页面截图或数据库回复，不发送账号密码/临时下载凭据：

- Dret与Daret分别包括什么，0.01还是1表示1%，分红再投资和复权怎样处理；
- 停牌/非交易日收益为空或0的含义，缺失编码，退市收益及终端价值处理；
- DRET两个市场平均收益字段对应哪些市场，怎样按证券市场连接；三因子Exchflg=2/Mktflg=A的范围和加权口径；
- 行业分类标准、IfPerformed执行状态及更正/取消的历史可见性；
- 主股东ShRank并列规则、SHSer/ShrSer_Type组内含义、GDID跨期稳定范围及覆写/原版关联。

### P0：历史证券基本资料与代码/上市有效区间

在RESSET检索“股票/证券基本资料、上市信息、证券代码变更、退市/终止上市历史”等业务关键词；精确产品名以你的实际页面为准，不编表代码。

需要稳定证券标识、上市公司码/原公司码各自命名空间、股票交易码及旧新代码有效区间、A股类别、交易所/市场、上市日期、最后交易/暂停上市/终止日期，以及转换/合并继承链接和相关公开/生效日期。不要只选今天仍上市的股票。

这决定预测时股票池，不得用“未来五天有完整收益的股票”倒推当时股票池，也不能将DRET首次/最后出现日当上市/退市日。

### P0：日综合行情DRESSTK及停复牌/估值

优先查看DRESSTK可选字段，保留原表头与原值：

- 日期、股票交易时代码、证券稳定标识、ComCd/CompanyCode、市场；
- 日上市状态与**实际交易/停牌状态**，停牌起止、复牌日期；Listedstate不一定足以表示每天是否交易；
- 原始收盘价、最后成交日期、官方估值/总回报指数（若提供）、Dret/Daret；
- 复权乘子或调整价的定义，除权除息日期、分红/送转及转换信息；
- 对发生终止/转换的证券，需能解释五日端点的持有价值。

停牌不能因为CSV空值就设0；消失不是无损失，也不直接设-100%。若有起点和端点总回报指数，可在口径和身份连续性确认后解决同一五市场日端点结果。

### P0：明确的市场日收益/指数系列

需要带**交易所标志、市场标志或指数代码**的日收益/市场指数数据，明确全A股或具体市场范围、加权方式、日期和总回报/资本收益口径。优先核对已有因子和DRET市场字段说明；能解释并分离原记录就不重复买，不能解释时再导正式系列。

### P0：退市、合并转换与终端结果

仅针对研究期间发生相应变化、且五日结果无法确定的证券补证：最后交易、整理期、终止日期、现金补偿/清算款的金额及生效/支付时间、继承证券、转换比例和可用估值方法。后来的最终回收款不能无条件回填为第五个市场日价值。没有可信端点时保留未知结果。

### P1：历史行业起点归属

先用已恢复的执行状态和标准字段核现有表。若只含变更而缺2015起点归属，请补原本已经有效的行业基准与历次公开、生效、取消/更正，统一证监会门类标准。当前没有历史成分权重，不自行造“剔除目标后的加权行业指数”。

### 有益，但不是原始损失标签成立的前提

成交量额、换手率、总/流通股数及市值能加强价格/流动性基线；若DRESSTK一次可选，可同时导出。更细行业、财务科目只在真实披露日期和有效史支持时采用。当前不要求延长2025/2026、不重新导整个股东表、不要求你手工清洗百万行。

## 5. 未解决前如何交付

候选数据与认证数据分开。预测总体候选仅根据过去/当前观察，结果左连接，未知标签不填0，候选和认证监督掩码分别保留。正式训练被认证门槛阻塞，数据缺口不会通过“改成无风险”消失。

每日期和行业记录N、已知结果O、未知M、正例B，完整总体损失比例界限为`[B/N,(B+M)/N]`；可评价子集上的B/O或AP不冒称完整市场结果。模型输出风险概率、数据/辅助降级与校准状态，不生成“保证没风险”的结论。
