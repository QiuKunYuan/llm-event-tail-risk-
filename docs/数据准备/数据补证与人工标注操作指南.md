# 数据补证与人工标注操作指南

更新：2026-11-24。适用题目：**披露时点感知的A股短期尾部风险预测**。本轮实际产物与测试见[准备验收](../数据核查/标注工具与来源映射验收-2026-11-24.md)。

**你先做两件事：读200条试标公告并填写中文Excel；从RESSET取得股东字段解释和必要的小样本补导。编码映射、数据清洗、检查程序由我来做。现在不用租GPU，不用标完16万条，更不用手工清洗400万行股东。**

## 1. 业绩预告用来干什么

这里是上市公司发布的“业绩预告”，不是分析师预测，也不是让你重新整理年报。例如公司说本期预计净利润同比增长、亏损扩大，或销售/成本发生变化。

我们先用人工样本训练和评价Qwen能否从文字抽出三个字段，再让冻结的抽取器处理研究范围内的其他公告。风险模型把预测字段和正文表示作为辅助信息，与收益主干、股东图一起预测未来五日尾部风险。

你标的是**公告说了什么**，不是“我认为股价会涨还是跌”。人工金标是认真阅读后形成的标准答案；模型自动生成、未经人工核对的答案不能冒充金标。

### 为什么要核查公开日期与更正

假设报告期结束于3月31日，预告4月20日才公开：不能让模型在3月31日就知道预告。若5月发布更正，也不能把更正内容回填到4月20日。只有日期、没有可靠时分秒的披露，统一从发布后的下一个市场交易日起进入特征。

需要保留原版与更正版的发布时间和关系，而不只是下载更多条数。这项程序核查由我做；你有原版公告链接、附件或数据库版本规则时，交给我作为证据。标注时不要找后来实际业绩或价格来“纠正”给定正文。

锁定样本1500=训练800、验证200、独立测试500。200试标包含在训练800中；300双标包含在1500中。已选好，不需要你抽样。

| `独立试标_42条_B.xlsx` | 第二位标注者独立做，不看你的答案 |
| `规则冻结后_余1300条_A.xlsx` | 试标问题解决、规范冻结后你再做 |
| `规则冻结后_余258条_B.xlsx` | 第二位标注者在规范冻结后继续 |

200与1300合起来才是1500。42是200与既定300双标的交集，42与258合起来才是300，不另抽一批200双标。暂时没有第二位标注者时，可以先完成你自己的200；独立一致性和最终金标尚不能放行。

Excel中的正文是待读材料，不是答案。所有真实标签初始为空；练习例子是虚构的，不混入真实样本。不要使用旧的300/60试标文件，也不要混用旧annotation-pack-v2。

## 3. 打开Excel后怎么填

打开“待标注”工作表，先读B列完整正文。只填写C—L；A/B和M—R是原始编号、正文、日期等来源，不能改。显示不全可选中正文看编辑栏或调整行高，不要删句子。不要插入、删除样本行，不用宏/公式，不另存成旧.xls。

| 列 | 名称 | 你怎么填 |
|---|---|---|
| C | 业绩方向 | 从下拉列表五选一 |
| D | 原因状态 | 已说明、未提及或待讨论 |
| E | 明确原因 | 已说明时每行一条短语；Excel里Alt+Enter换行 |
| F—H | 原文证据1—3 | 复制1—3段正文原话；不用的证据格留空 |
| I | 置信度 | 高、中、低；低置信度要写疑问 |
| J | 填写状态 | 未完成、已填写、待讨论 |
| K | 疑问或备注 | 比较期不清、多个指标冲突、疑似截断等写在这里 |
| L | 耗时秒 | 可选，填非负有限秒数；可留空 |

**不用你写JSON，不用你写代码。** 导入、转换、逐字证据检查和错误清单由程序完成。

### 方向怎么选

| 方向 | 什么时候选 |
|---|---|
| 改善 | 利润/收入上升、亏损收窄、扭亏或明确经营改善 |
| 恶化 | 利润/收入下降、亏损扩大或明确经营恶化 |
| 基本稳定 | 正文明说与同期基本持平，而非你看不懂 |
| 混合 | 有明确、重要且方向相反的表现；多个指标不自动算混合 |
| 不明确 | 已读完但比较基期/信息不足，不能判断方向 |

“还在赚钱”不等于改善，“还在亏钱”不等于恶化。比较的是公告明确表达的变化。没有说明原因时，方向可以很明确；选原因“未提及”即可。没有读完则保留“未完成”，不能拿“不明确”凑数量。

### 原因怎么填

只写正文明确给出的解释，例如“产品销量增加”“原材料成本上升”。允许简短概括，不允许猜。

- 有明确原因：D选已说明，E每行写一条。
- 没说原因：D选未提及，E留空；程序会转成空原因数组。
- “非经常性损益影响”是原文所说时可以保留这个概括，不能自己补成资产处置、政府补助等具体事件。
- 不把“利润下降”这种结果再当成原因；不查新闻补“行业不景气”。

### 证据怎么填

从同一条B列正文复制，不能改写、添加省略号或从网页补句子。一段原句同时支持方向和原因时，一段即可。程序只确认引文存在于原文，不代表语义一定正确。

### 看不懂怎么办

填写你能确定的部分，J选待讨论，K写具体疑问。比如：“只有净利润800万元，没有同比基期，方向能否判断？”不要为了完成任务猜一个值。低置信度也要说明原因。

## 4. 六个虚构练习

以下不是实际公告，不是已经完成的金标。

| 虚构正文 | 方向 | 原因 | 说明 |
|---|---|---|---|
| 预计净利润同比增长30%，主要由于产品销量增加。 | 改善 | 产品销量增加 | 证据可复制整句 |
| 预计净利润800万元，上年同期1000万元，下降主要由于原材料成本上升。 | 恶化 | 原材料成本上升 | 仍然盈利，但比同期下降 |
| 预计亏损300万元，上年同期亏损1000万元。 | 改善 | 未提及 | 亏损收窄，尚未扭亏 |
| 预计本期业绩与上年同期基本持平。 | 基本稳定 | 未提及 | 原文明说持平 |
| 预计营业收入明显增长，但净利润同比下降，主要由于成本上涨。 | 混合 | 成本上涨 | 两个重要指标明确反向 |
| 预计净利润为800万元。 | 不明确 | 未提及 | 没有比较基期或变化方向 |

每例证据都从该例原句复制。遇到区间跨方向、多个报告期或措辞不清时，按照[完整规范](../../project/docs/公告人工标注规范-v1.md)写疑问，不凭中点或元数据代码猜。

## 5. 标完后发生什么

1. 保存并通过允许的私有方式返回.xlsx，保留你的独立原稿。
2. 我导入程序，给你待修复清单：未填、方向不合法、选未提及却写了原因、证据不在正文、编号/正文被改等。
3. 第二人独立标完对应42后，先计算方向一致率/Kappa，再看分歧。原因短语或证据不同不自动表示谁错，需要读原文。
4. 用“裁决与复核.xlsx”处理分歧、低置信度与疑问，写明判断理由。不能先商量后假装独立标注。
5. 人工确认复核后，程序按编号形成金标。已填写不等于已批准，未讨论完不能进入训练。
6. 规范在训练试标后冻结，再做1300/258，最终按800/200/500转换。测试500只用于独立评价，不用于改规则、提示或调参。

空模板初检没有一致性成绩，Kappa不能凭空填写。即使全部方向一样，Kappa也可能无定义，不能简单写“1”。

## 7. 主体与证券映射是什么意思

### 上市公司与证券

同一家公司在收益表可能用股票交易代码，在公告或股东表用数据库上市公司内码。程序必须确认这些记录指向同一家公司，并且在相应历史日期有效。当前名称或今天的证券关系不能直接回填所有历史。

我核查发现转换器曾按工作簿列顺序选公司码：部分年份取CompanyCode，其他年份取Comcd，混用了两套码。这是程序问题，由我修复、另目录加工及逐行核验。不能把旧混合码统计当真实公司代码变更，也不因这个发现就宣布已验股票—日期标签失效。

新的对应表先记“在DRET中观察到的对应关系”。最早/最晚观察日不是正式上市/退市日期；缺股票码的行不能只因观察到一个候选就自动补入。需要官方历史关系的具体歧义项，再交你补来源。

### 股东机构主体

要分清名字/ID代表个人、机构、基金产品、基金管理公司还是名义托管。产品与管理人不是自动同一个节点，相似名字也不能随意合并。两个公司被同一个已核实机构/产品持股，才构成我们需要的共同持股关系。主体身份与名单完整性不同，必须分别认证。
