## 阶段一：开题冲刺（约1—2周）

**目标：通过开题答辩。不是学会所有理论，是能讲清自己的研究设计。**

### 要学的（按优先级）

1. **自己方案的"主线四句话"**（已有材料：`docs/导师汇报/硕士论文选题导师汇报-零基础逐页讲解.md`）
   - 预测什么：未来5个交易日、剔除市场因素后的异常下跌（尾部风险）
   - 怎么做：Qwen读公告→结构化事件；共同股东→关系图；GRU读历史行情；门控融合出概率
   - 为什么可信：时间切分防偷看未来、消融实验证明每个模块有用
   - 边界在哪：不声称证明风险传染，只检验预测增益

2. **核心概念白话版**（都在讲解稿第二部分，只看这些就够）
   - 收益率/波动率/换手率 → 尾部风险 → 共同冲击 vs 公司特有风险
   - 因子模型与残差（"扣掉大盘影响剩下的部分"）
   - 训练/验证/测试集 + 数据泄漏
   - PR-AUC、消融实验

3. **母论文AAAI 2025 DGNN-SR读三遍**（PDF在桌面"论文"）
   - 第一遍：摘要+引言+模型总图（它解决什么问题）
   - 第二遍：时间编码+自适应重加权（继承的核心是什么）
   - 第三遍：实验与消融（怎么证明模块有效——照着学实验设计）
   - 读完自己列一张"原论文 vs 我的方案"对照表（改动点：任务、数据、关系来源、标签）

### 要做的

- [ ] 向导师汇报，拿到：题目最终确认、开题模板、截止日期、导师修改意见
- [ ] 开题报告初稿（已有素材：研究现状初稿 + 整体方案文档 + 数据核查文档，按学校模板拼装）
- [ ] 把"动量因子只有月频"作为一个技术决策点向导师提出（自构造日频 vs 降级三因子）

### 阶段产出

- 开题报告 + 答辩PPT；导师意见记录（认可项/质疑项/否定项逐条写下来）

## 阶段二：数据审计与清洗（约2周，可与阶段一并行）

**目标：把现有授权数据整理为能构造标签、特征和实验切分的研究面板。**

### 要学的

- **流式表格处理**：分片读 XLSX，只保留需要的列，输出本地压缩数据文件；避免一次性读入数百万行
- **数据审计思维**：每个表先问四个问题——多少行多少列？缺失在哪？时间覆盖？主键是什么？
- **"当时可得"原则**：所有决策只看一个问题的答案——"这个信息在那个日期，市场知道吗？"

### 要做的（顺序固定）

- [ ] 审计本地字段、时间覆盖、代码格式、重复和缺失；原始压缩包保持不变
- [ ] 三段日收益拼成一张表；以实际审计覆盖为准（本地 DRET 目前到2024-07-31）
- [ ] 公司代码映射表（业绩预告的ComCd ↔ 日收益的Stkcd，用证券代码变更表串联改名改码）
- [ ] 构造风险标签：滚动250日因子回归→残差→未来5日CAR→历史10%分位阈值→正样本标记
- [ ] 统计两个关键数字：**实际正样本比例**、**共同股东图覆盖与边密度**，据此决定模型规模

### 阶段产出

- 清洗后的研究面板（公司×日期大表）+ 数据审计报告（缺失率、分布统计）

## 阶段三：事件抽取（约3周）

**目标：做出可评估的公告事件结构化结果；微调属于后续选项。**

### 要学的

1. **大模型微调概念**（先概念后动手）
   - SFT（监督微调）：给模型看"公告→JSON"的例子让它学
   - LoRA/QLoRA：冻结大模型只训小增量矩阵（省显存的关键）
2. **动手环境**：先比较提示词模型输出；确认抽取有增益后，再租单卡跑小模型LoRA/QLoRA
3. **标注规范设计**：先做简单、可复核的事件类别和方向标签，减少主观原因与严重程度标注
4. **评价方法**：Precision/Recall/F1的宏观平均，span匹配

### 要做的

- [ ] 先从业绩预告抽样300条，确定事件类型、方向和证据字段
- [ ] 对一小批样本比较规则、提示词模型和人工结果
- [ ] 冻结标签规范后形成约600—1,000条标注集，按时间切分；抽一部分双人复核
- [ ] 需要微调时从Qwen3-1.7B或同级模型开始，小样本试训并和提示词基线比较
- [ ] 只在人工测试集质量过关后，缓存批量抽取结果

### 阶段产出

- 抽取质量报告 + 可复用的事件JSON缓存；若微调有增益，再保存小模型权重

## 阶段四：风险预测模型（约4周）

**目标：跑通"最低可交付版本"，证明信息融合的增益。**

### 要学的

1. **LightGBM**：先把结构化基线和消融跑通
2. **共同股东图特征**：先算邻居数量、关系强度和邻居历史风险汇总
3. **GRU/GraphSAGE/门控融合**：只在基线、标签和股东图通过检查后作为扩展

### 要做的（顺序是先基线后模型，每步有对照）

- [ ] 基线：历史风险频率、逻辑回归、LightGBM
- [ ] 逐步加入 RESSET 结构化预告字段、小模型事件语义、共同股东邻居特征
- [ ] 对照真实股东图、行业图和随机图；报告每个信息源带来的增量
- [ ] 时间允许且图有信号时，再做GraphSAGE或门控融合

### 阶段产出

- 可复跑基线与特征代码 + 消融结果表 + walk-forward样本外指标

## 全程贯穿的三条习惯

1. **每次实验记录三件事**：跑了什么配置、结果数字、和上次比差异——直接写进GitHub commit message；
2. **卡住先查讲解稿**，再问我。讲解稿没覆盖的概念，要求我用"村庄比喻"级别解释；
3. **数据相关的任何操作都先问一句**："这一步会不会看到未来？"——防泄漏是全文可信度的地基。
