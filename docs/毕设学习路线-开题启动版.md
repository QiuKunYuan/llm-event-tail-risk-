# 毕设学习路线（开题启动版）

> 目标：从现在到开题答辩，再到第一轮实验跑通，每个阶段该学什么、做什么、产出什么。
> 原则：不学"全部理论"，只学"下一阶段马上要用"的部分；每个概念第一次遇到时搞懂，用的时候再加深。
> 材料已就位：桌面"论文"文件夹（4篇核心论文）、"论文选题图"（结构图）、"RESSET论文数据"（927MB数据）、GitHub仓库（文档全在里面）、讲解稿（零基础版，含术语白话）。

## 阶段一：开题冲刺（约1—2周）

**目标：通过开题答辩。不是学会所有理论，是能讲清自己的研究设计。**

### 要学的（按优先级）

1. **自己方案的"主线四句话"**（已有材料：`docs/导师汇报/硕士论文选题导师汇报-零基础逐页讲解.md`）
   - 预测什么：未来5个交易日、剔除市场因素后的异常下跌（尾部风险）
   - 怎么做：Qwen读公告→结构化事件；共同股东→关系图；GRU读历史行情；门控融合出概率
   - 为什么可信：时间切分防偷看未来、消融实验证明每个模块有用
   - 边界在哪：不声称证明风险传染，只检验预测增益

2. **核心概念白话版**（都在讲解稿第二部分，只看这些就够）
   - 收益率/波动率/换手率 → 尾部风险 → 共同冲击 vs 公司特有风险
   - 因子模型与残差（"扣掉大盘影响剩下的部分"）
   - 训练/验证/测试集 + 数据泄漏
   - PR-AUC、消融实验

3. **母论文AAAI 2025 DGNN-SR读三遍**（PDF在桌面"论文"）
   - 第一遍：摘要+引言+模型总图（它解决什么问题）
   - 第二遍：时间编码+自适应重加权（继承的核心是什么）
   - 第三遍：实验与消融（怎么证明模块有效——照着学实验设计）
   - 读完自己列一张"原论文 vs 我的方案"对照表（改动点：任务、数据、关系来源、标签）

### 要做的

- [ ] 向导师汇报，拿到：题目最终确认、开题模板、截止日期、导师修改意见
- [ ] 开题报告初稿（已有素材：研究现状初稿 + 整体方案文档 + 数据核查文档，按学校模板拼装）
- [ ] 把"动量因子只有月频"作为一个技术决策点向导师提出（自构造日频 vs 降级三因子）

### 阶段产出

- 开题报告 + 答辩PPT；导师意见记录（认可项/质疑项/否定项逐条写下来）

## 阶段二：数据审计与清洗（约2周，可与阶段一并行）

**目标：把927MB原始数据变成一张可用的研究面板。这一步不写论文，只跑数字。**

### 要学的

- **pandas基础操作**：读xlsx、拼接、分组统计、透视表——够用就行，边做边查
- **数据审计思维**：每个表先问四个问题——多少行多少列？缺失在哪？时间覆盖？主键是什么？
- **"当时可得"原则**：所有决策只看一个问题的答案——"这个信息在那个日期，市场知道吗？"

### 要做的（顺序固定）

- [ ] 解压全部zip，逐表跑审计脚本：记录数、缺失率、公司数、时间覆盖（我之前给的六步清洗法，第一步）
- [ ] 三段日收益拼成一张表（2015-2025连续日频面板）
- [ ] 公司代码映射表（业绩预告的ComCd ↔ 日收益的Stkcd，用证券代码变更表串联改名改码）
- [ ] 构造风险标签：滚动250日因子回归→残差→未来5日CAR→历史10%分位阈值→正样本标记
- [ ] 统计两个关键数字：**正样本比例**（预期约10%）、**共同股东图边密度**——这两个数决定后面模型可训性，也写进开题可行性

### 阶段产出

- 清洗后的研究面板（公司×日期大表）+ 数据审计报告（缺失率、分布统计）

## 阶段三：事件抽取（约3周）

**目标：微调出Qwen事件抽取模型，产出结构化事件库。**

### 要学的

1. **大模型微调概念**（先概念后动手）
   - SFT（监督微调）：给模型看"公告→JSON"的例子让它学
   - LoRA/QLoRA：冻结大模型只训小增量矩阵（省显存的关键）
2. **动手环境**：Python + transformers + peft库；实验室4090申请使用流程
3. **标注规范设计**（看ACL 2024 EFSA的五元组体系，PDF在桌面）
4. **评价方法**：Precision/Recall/F1的宏观平均，span匹配

### 要做的

- [ ] 从业绩预告抽样300条，定义标注字段（事件大类/细类/情感/原因/数值区间）
- [ ] 用未微调Qwen跑一遍零样本，看输出差距——这成为天然的"微调前基线"
- [ ] 试标注→冻结规范→两人交叉标注→算Kappa一致性
- [ ] QLoRA微调Qwen3-8B（配置参数方案文档里已写好：rank 16/32、lr 5e-5等）
- [ ] 指标达标后冻结模型，批量抽取全部历史公告

### 阶段产出

- 微调模型权重 + 事件JSON库 + 抽取质量报告（各字段F1）

## 阶段四：风险预测模型（约4周）

**目标：跑通"最低可交付版本"，证明信息融合的增益。**

### 要学的

1. **PyTorch基础**：Dataset/DataLoader/训练循环——够跑模型即可
2. **GRU**：处理序列的门控网络（代码层面就是`nn.GRU`，重点是输入怎么组织）
3. **GraphSAGE**：邻居聚合（重点不是公式，是图数据怎么存：邻接表+特征矩阵）
4. **门控融合**：一个可学习的0-1权重，决定"自身信息vs邻居信息"各听多少

### 要做的（顺序是先基线后模型，每步有对照）

- [ ] 基线：历史频率、逻辑回归、XGBoost（结构化特征直接喂）
- [ ] 无图GRU（只有历史行情）→ 加事件表示（有无事件的对照）
- [ ] 共同股东图构建（按信息发布日期对齐快照，阈值+TopK构图——参数方案已定）
- [ ] GraphSAGE + 门控融合完整模型
- [ ] 消融矩阵：去事件/去图/换随机图/换拼接——每个模块的贡献用数字说话

### 阶段产出

- 完整训练代码（进GitHub）+ 消融结果表 + walk-forward样本外指标

## 全程贯穿的三条习惯

1. **每次实验记录三件事**：跑了什么配置、结果数字、和上次比差异——直接写进GitHub commit message；
2. **卡住先查讲解稿**，再问我。讲解稿没覆盖的概念，要求我用"村庄比喻"级别解释；
3. **数据相关的任何操作都先问一句**："这一步会不会看到未来？"——防泄漏是全文可信度的地基。
