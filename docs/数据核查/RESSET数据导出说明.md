## 加工与股东字段修复

XLSX采用ZIP/XML流式读取，不使用不存在的`pandas.read_excel(chunksize=...)`。加工脚本为`scripts/prepare_resset.py`；原始档案不改写。

股东原始表头已核对：`信息来源_InfoSource`、`股东序号()_SHSer`、`更新时间_UpDt`。以前两个别名未匹配，旧CSV没有三字段；本轮已修复并把4,036,775行写到仓库外新目录 `/home/admin/workspace/.thesis-validation/shareholders-v2/`，四份工作簿均无未匹配字段。旧processed保留用于核对。

```bash
python3 scripts/prepare_resset.py \
  --root /path/private/RESSET论文数据 \
  --output /path/private/shareholders-v2 --only shareholders
python3 project/scripts/audit_shareholder_disclosures.py \
  --input /path/private/shareholders-v2/shareholders.csv.gz \
  --output /path/private/shareholder-group-audit.json
```

本轮全量分组审计：206,223候选组中189,735存在重复排名，160,294组为20行；SHSer有723个不同值；来源缺失33行。典型的20行可能涉及两套名单，但当前不能仅凭行数证实。SHLst是股东名字，绝不是`SHLst=1`的名单类型标识；SHSer也不能未经词典确认当组类别。

完整名单组需要公司/报告期/公开日/来源和实际名单口径、修订证据；凑够10个排名不等于认证完整。UpDt不是公众首次可见日，2025/2026更新不能被隐瞒。当前`main_graph_ready=false`，后续须完成原公开组/实体/版本核验。

## 标签与时间口径

已有标签6,116,554行，2017-02-06—2024-07-24，P10正类669,391、P5正类358,973。原始报告与标签留在processed，既有标签仍需独立复算并绑定新代码/输入哈希。

252个收益/无风险收益/因子均有效的历史观测拟合FF回归；冻结起点系数计算未来连续五个市场日残差和；阈值取最近252个已完成历史五日结果，第26项P10/第13项P5，严格小于记正类。日历来自实际全市场日期；未来缺失不补齐。

日期级公告与持股从下一市场交易日生效；新完整持股披露替换整个旧名单，不能逐边永久沿用消失股东。实际预测区间不含2025；禁止只修改配置年份而不重做输入/标签/全部对照。

公开字段与标签聚合审计分别见[字段审计](../../project/docs/数据字段映射与质量审计.md)、[标签审计](../../project/docs/标签和基线审计结论.md)。具体全链路就绪门槛见[构成与可行性论证](../开题方案/毕设构成与可行性论证.md)。
