# 实施版研究设计

> 本文作为当前执行方案，优先保证问题清楚、数据可用、实验能完成。旧方案仅作参考；本研究不以因果风险传染为结论。

## 题目

**基于大语言模型公告事件表征与时变共同机构持股关系的上市公司短期尾部风险预测研究**

## 研究问题

在仅使用预测时点可得信息的条件下，公告文本中的事件语义和共同机构持股关系，能否在公司自身历史收益特征之上，提高对未来 5 个交易日条件异常下跌的样本外预测能力？

本文研究预测性关联，不声称证明公司之间存在因果风险传染。

## 可用数据与范围

本地 RESSET 导出已覆盖核心研究链路：

| 数据 | 当前导出 | 本研究用途 |
|---|---:|---|
| 日收益 DRET | 2015-01-05—2024-07-31，9,091,641 行 | 收益、无风险利率、市场收益、行业代码、历史波动特征和标签 |
| 日三因子 | 约 2.4 万行 | Rmrf、SMB、HML，构造条件异常收益 |
| 证监会行业日收益 | 约 5 万行 | 行业调整标签的稳健性分析 |
| 业绩预告 | 约 16.2 万条 | 主公告文本与已有结构化数值字段 |
| 诉讼仲裁 | 约 2.1 万条 | 辅助事件计数和稳健性分析 |
| 主要股东名单 | 约 404 万行 | 按公开披露时间构造共同机构持股图 |
| 行业、上市状态变更 | 已导出 | 历史行业和状态控制 |

主样本使用全部 A 股，不按当前指数成分筛选。交易数据从 2015 年开始，先留出因子回归和历史分位数的预热期，预计从 2018 年开始正式建模，止于 2024-07-31。2024 年只作为部分年度测试期。三因子文件虽延伸至 2025 年，但预测样本以 DRET 实际覆盖期为准。暂不使用未导出的财务指标、日市值、违规处罚文本和换手率。当前换手率工作簿实际只有股票代码与日期列，没有换手率数值列，因此不作为特征。

本地字段审计还发现 DRET 有 443,905 行缺个股收益值，这些行不参与因子估计或标签计算；个股代码列完整。诉讼仲裁的 `EventCon` 在当前导出中全空，但 `ActDes` 有文本，故只作辅助事件特征，不作为主 LLM 语料。

## 风险标签

1. 对每家公司用截至预测日 (t) 的最近 252 个有效日收益估计滚动三因子模型：个股超额收益对 RESSET 日频 Rmrf、SMB、HML 回归。三因子按 `Exchflg=2, Mktflg=A` 取流通市值加权口径；在 2,329 个共同交易日上，该 Rmrf 与 DRET 的流通市值加权市场收益减无风险利率平均绝对差约为 0.000039。
2. 冻结截至 (t) 的系数，计算 (t+1) 至 (t+5) 五个连续市场交易日的因子残差之和。未来五日中有停牌或收益缺失时，该预测样本不生成标签。
3. 若未来五日累计残差低于该公司此前已完成的最近 252 个有效窗口的经验第 10 百分位（nearest-rank），标签记为 1；第 5 百分位作稳健性分析。预测日 t 的阈值只纳入在 t 收盘前已经结束的结果窗口。
4. 历史分位数只用已结束的窗口；标签窗口相互重叠，所有训练、验证、测试边界 purge 至少 5 个交易日。

行业收益用于替代标签的稳健性分析，避免把多种行业调整口径叠加进主标签。月频动量因子不映射到日频；缺少日频动量不阻碍主研究。

## 两类新增信息

### 公告事件

业绩预告作为主要 LLM 语料，诉讼仲裁先作为已有结构化事件字段和事件计数。日期没有时分秒，公告从下一交易日生效。保留数据库已有的预告类型和数值字段，LLM 重点抽取方向、简化事件类别和可核验的文本证据，不重复抽取已存在的数值。

先标注 300 条试样并定稿规范，再形成约 600—1,000 条人工标注集；按时间划分训练、验证和测试样本，重复公告按事件分组，避免同一事件跨集合。两名标注者复核一部分样本，报告分类一致性。先评估提示词抽取；有稳定增益时再对 Qwen3-1.7B 或同级模型做 LoRA/QLoRA。QLoRA 属于模型对比，不是开题可行性的前置条件。

### 共同机构持股关系

全量初审发现 `PctTrdShr` 非空约 178.7 万行，其中 `ShRank<=10` 约 177.7 万行；非自然人持有人中约 7.5% 缺 `GDID`。样例显示同一公司、报告期和股东会出现总股东与流通股东两组记录：流通股东组的 `PctTrdShr` 有值。先用 `PctTrdShr` 非空且 `ShRank<=10` 的记录构图，排除自然人及缺少 `GDID` 的记录，按 `GDID` 和 `SHChrct` 识别共同持有人；`SHLst` 是股东名称，不能当作名单类型代码。使用 `InfoPubDt` 作为可用时间，不按报告期结束日提前生效。月末生成当时已公开信息的图快照，构造共同持股强度和邻居历史风险等少量特征。再统计节点覆盖率、孤立节点、边密度和披露陈旧度，达标后才考虑 GraphSAGE。

## 模型与实验

以 LightGBM 为主预测器，避免一开始同时训练多个深度模型。使用完全相同的时间切分逐步加入信息：

1. 公司自身历史收益、波动和市场状态基线；
2. 加入 RESSET 已有预告类别和数值字段；
3. 加入小型指令模型抽取的公告语义；
4. 加入共同股东图的邻居汇总特征；
5. 时间允许时，将 LightGBM 升级为 GRU/GraphSAGE 加门控融合模型。

当前已归档的首轮基线是流程试跑：每折用测试年之前的历史样本训练，测试年固定，参数预先固定，没有单独验证集。后续若调参，必须在测试年之前划出时间顺序验证集；不能用测试年份选择特征、阈值或超参数。正式方案需把训练/验证/测试日期写入机器可读配置，并在论文中明确首轮结果与最终实验的区别。

预测按年份扩展窗口滚动评估：例如训练 2018—2020、验证 2021、测试 2022；再训练至 2021、验证 2022、测试 2023；最后训练至 2022、验证 2023、测试 2024-01 至 2024-07。训练、验证、测试边界至少 purge 五个交易日。主指标为 PR-AUC，辅助报告 Recall@K、正类 F1、ROC-AUC 和 Brier 分数。模型提升通过按交易日区块抽样的置信区间评估。对照图包括行业图和随机图；不把图模型或 LLM 的增益预先写成结论。

## 实施顺序

1. 流式读取已有 XLSX 分片，核实字段、日期、代码、重复记录和缺失率，转换为本地压缩 CSV；原始授权文件保持不变，不提交 Git。
2. 按证券代码、日期排序 DRET，与三因子对齐并建立交易日历。
3. 运行 `scripts/build_tail_risk_labels.py` 构造首轮基线面板；输出位于本地数据目录 `processed/tail_risk_labels.csv.gz`，包含截至预测日收盘的 1/5/20 日收益、20/60 日波动和市场因子等字段，以及未来尾部标签；同目录附有生成口径报告。随后先跑标签频率、逻辑回归和 LightGBM 基线。
4. 统计公告和股东图覆盖情况；制作小规模标注集，比较规则、提示词模型和小模型微调。
5. 逐项加入事件与关系信息，完成消融和稳健性分析。

当前运行容器内存约 8.8 GiB、没有可见 GPU，Excel 应分片流式读取；Qwen 微调放在单卡租用环境，先用小模型和短上下文试验，再决定是否继续投入算力。
