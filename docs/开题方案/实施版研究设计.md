# 完整毕业设计研究设计报告

> 版本：2026-11-23。本文为本项目固定执行方案，替代此前将股东图、图神经网络和深度融合列为扩展项的草案。标题与方法是当前工作稿，最终仍按导师及学院格式要求修订。报告只把实验结果作为待检验事实，不预设新模型一定优于基线。

## 1. 研究题目与结论边界

**题目：时点感知门控融合的A股尾部风险预测**

研究对象是上市公司自身的短期尾部风险。对每个公司—交易日，在当日收盘信息可用的前提下，预测之后五个交易日的公司特有异常下跌标签。研究不预测“某条新闻是否导致另一家公司下跌”，不识别因果风险传染，也不把预测分数解释成投资建议。

所有主线模块均按必做设计：量价时序 GRU、公告事件抽取、时点共同机构持股异构图、GraphSAGE 关系编码、带信息可用状态和信息陈旧度的门控融合、二分类风险头、同样本时间外比较和消融。Qwen3-1.7B QLoRA 是公告事件抽取的固定实现。首轮抽取训练是否通过独立质量门槛是实验过程中的质量判定，不改变研究模块；若模型输出质量有限，必须完整报告抽取误差及其下游影响，不能把低质量输出伪装成有效特征。

## 2. 研究问题与可证伪假设

### 核心问题

仅使用预测日收盘时已经公开的信息，把公告事件语义、公司自身收益时序与按公开时点更新的机构持股关系融合，能否比相同标签、相同样本和相同时间切分上的表格基线更好地识别未来五个交易日的尾部风险？门控是否能在事件缺失、股东披露陈旧或模态覆盖变化时，优于简单拼接？

### 假设

- **H1（量价时序）**：由日收益及市场因子组成的 GRU 序列表示，在锁定的时间外样本上优于相同输入的简单表格模型。
- **H2（公告增量）**：人工核验的公告事件字段在量价信息之外带来可测量的样本外 AP 增量。
- **H3（关系增量）**：按真实披露时间构建的共同机构持股图表示，在量价和公告信息之外带来可测量的样本外 AP 增量。
- **H4（融合机制）**：以模态可用状态和信息陈旧度为条件的门控融合，相较于简单拼接、固定权重融合及单一模态模型，取得更稳定的时间外表现。

这些是假设，不是结论。若提升小于区块置信区间或只出现在单一测试期，论文应报告未获得稳定增益。模型预测成功率不可能在实验前百分之百保证。

## 3. 同方向研究与本课题定位

本研究已有明确同方向先例，不能以“首次把文本、图神经网络用于股票风险预测”作为创新主张。

1. Hou 与 Liu（2023）直接研究机构交叉持股与股价崩盘风险，是本课题股东网络方向最接近的研究之一。两者都关注机构持股关系与股价尾部风险；本课题的区别在于日频、未来五日的预测任务，将公告内容与关系图一起输入模型，并以严格披露时点和时间外 AP 增量作为评价对象。具体变量和样本设定须继续阅读全文核对。
2. 彭俞超、王南萱、顾雷雷（2023）基于2012—2019年A股年报文本研究预判性数字化披露与未来股价暴跌风险。它已经证明“文本信息和A股崩盘风险”的结合并非空白。本课题拟使用日频公告而非年度报告主题，并检验五日风险预测中的多源增量。
3. Cheng 等（2022）提出金融时间序列多模态图神经网络；Feng 等（2019）的 Temporal Relational Ranking 研究时变股票关系下的股票预测。它们说明金融图预测方法已有基础，不能把 GraphSAGE 或关系建模本身当作创新。
4. Chen 等（2024）的 EFSA 研究中文财经新闻的事件级金融情感分析，可参考事件结构和标注方法；其语料为财经新闻，不等同于 RESSET 上市公司公告。
5. 传统股价崩盘研究通常以年度公司特征和年度崩盘指标开展实证分析。本文的预测对象、观测频率、标签构造和评估协议与解释性回归研究不同，需明确这是预测研究，不作因果解释。

### 创新主张的边界

拟贡献集中为一项方法设计和两项研究设计：在披露可用时点约束下联合建模高频公司收益序列、稀疏文本事件和低频持股关系；门控显式读入公告/图是否可用、最新披露年龄与有效边数量，学习根据输入质量调节模态权重；在同样本、跨年度时间外测试上逐块检验增量。该组合可作为本论文的应用性方法贡献，不能声称已证明国际首创。正式开题前要做中英文关键词、引文追溯和原文核查，确认是否有相同任务与相同组合。

## 5. 预测对象与标签定义

样本单位为公司 (i) 与交易日 (t)。预测时点是 (t) 收盘；公告和持股资料必须在该时点前公开。无可靠发布时间时，统一从发布日期后的下一个交易日生效。

对每家公司用截至 (t) 的最近 252 个有效日收益拟合滚动三因子回归：

\[
r_{i,s}-r_{f,s}=\alpha_{i,t}+\beta_{i,t}^{\top}F_s+\epsilon_{i,s},\quad s\le t,
\]

其中 (F_s=(Rmrf_s,SMB_s,HML_s))，主口径使用 RESSET 已核对的流通市值加权因子；估计系数在标签的未来窗口冻结。目标值为未来五个连续市场交易日残差之和：

\[
CAR^{(5)}_{i,t}=\sum_{k=1}^{5}(r_{i,t+k}-r_{f,t+k}-\hat\alpha_{i,t}-\hat\beta_{i,t}^{\top}F_{t+k}).
\]

将此前已完成的 252 个可用五日窗口按由早到晚计算的结果形成历史经验分布；只有窗口结果在 (t) 收盘前已完成时才可用于阈值。若 (CAR^{(5)}_{i,t}) 严格低于历史 nearest-rank P10 阈值，定义 `label_p10=1`，否则为 0。P5 是预先指定的稳健性标签。未来五日中个股收益缺失或窗口非连续时，该样本不生成标签。相邻目标窗口重叠，正式评估边界 purge 至少五个交易日，置信区间按交易日区块抽样。

该标签表达“给定三因子模型下相对公司近期自身分布异常偏低的五日收益”，不是破产标签、法定重大风险，也不保证收益必为负。

## 6. 固定模型：三路表示与可用性感知门控

### 6.1 日收益序列支路：GRU

输入为 (t) 日及之前最近 60 个交易日的日收益、超额收益和三因子字段；辅助加入由现有 DRET 直接计算的 5/20/60 日累计收益、20/60 日波动、60 日下行波动、有效观测比例。任何滚动量只向后计算。序列按训练期统计量标准化，缺失用有效位掩码表达，不用未来观测填补。

采用单层 64 维 GRU，取末时点隐状态 (h^{seq}_{i,t}\in\mathbb{R}^{64})，经线性层投影至 128 维。GRU 是量价分支的固定编码器，用于提供短期状态；LightGBM、Logistic 仍作为传统预测基线。

### 6.2 公告语义支路：Qwen3-1.7B QLoRA

人工标注约 1,500 条**业绩预告**，按公告/事件去重并按不同年份和 RESSET 预测类型分层抽样。首批 200 条试标仅从 2017–2019 训练年份抽取；规范冻结后补齐全部样本。为避免抽取器训练文本晚于首个风险测试期，固定按时间划分：2017–2019 训练、2020 验证、2021–2024-07 独立测试；实际各集合数量按样本分布报告，不将年份边界随机改成比例切分。不少于 20% 样本由两人独立标注并仲裁分歧；留后测试标签不得用于训练、字段修改或超参数选择。

事件 JSON 固定包含：预期经营/财务方向（改善/恶化/基本稳定/混合/不明确）、文本明确陈述的原因短语、支持标签的原文证据片段。业绩预告已有的预测类型、区间和数值直接保留 RESSET 原生字段，不让模型重新猜数值。诉讼仲裁不混入该业绩方向标签；以公开日期和事件类别构造辅助计数及最近事件年龄。输出校验 JSON schema，非法项计为错误。

用 Qwen3-1.7B 4-bit QLoRA 微调结构化抽取器；训练、验证、测试按时间和重复事件分组，防止近重复泄漏。主报告各字段 macro/micro F1、精确率、召回率、严格 JSON 合法率、方向一致率、证据片段命中率，并附人工一致性指标。模型将文本转为结构化类别、置信度与证据特征，不直接预测风险标签。

用微调 Qwen 的公告正文隐藏状态池化向量形成语义表示，并与经人工抽取校验的方向/原因/证据槽位、RESSET 原生预测类型及幅度字段一同投影。公司—交易日层面聚合最近 20 个交易日已生效的业绩预告表示，用可学习时间注意力加权；将同期诉讼仲裁事件数、来源类别和最近事件年龄作为辅助结构字段。无业绩预告时使用可训练空向量，同时将 `event_available=0` 提供给融合门。

### 6.3 股东关系支路：披露时点异构图 + GraphSAGE

构造按信息发布日期更新的公司—机构二部图。节点为上市公司和规范化机构；边记录持股比例、披露时间、报告期截止日与边年龄。报告截止日只是该持仓对应的统计时段，不能当作公众可见日。对 (t) 的快照，只保留 `InfoPubDt` 已发生且未被更新记录取代的最后一条有效披露；边年龄 (a_{ij,t}) 作为输入。过滤个人股东、无法映射主体及重复的总股东/流通股东重复行，优先保留口径一致且比例可用的流通股持股记录。

使用两层 GraphSAGE 对公司—机构—公司邻居进行采样和聚合；每个节点只输入在 (t) 已知的公司序列编码、机构度数/覆盖数等历史结构量、边持股比例和披露年龄。不得将邻居未来标签、未来收益和之后发布的持仓放入图或节点特征。得到 (h^{graph}_{i,t}\in\mathbb{R}^{128})。采样规模、层数和隐藏维度在验证期选择；不使用测试期挑参。

图时点审计固定输出：公司覆盖率、机构覆盖率、每个快照边数/孤立率、有效披露年龄分布、代码/机构映射失败率、变更生效延迟。报告机构名匹配人工抽查结果。图覆盖率不足仍须报告并分析其共同样本影响，不以删除图覆盖差样本的方式美化模型结果。

### 6.4 核心机制：可用性与新鲜度条件门控

三路表示投影到相同维数 (d=128)：(z_m=W_mh_m)，模态 (m\in\{seq,event,graph\})。为每一路构造预测时点可用状态 (a_m\in\{0,1\}) 和信息年龄/缺失比例 (q_m)。GRU 序列通常可用；公告可用性由有效事件数决定；图可用性由有效公司边决定，图新鲜度由边龄摘要（如中位数、最大值）表达。

门控权重为：

\[
g_{m,i,t}=\operatorname{softmax}_{m}\left(\operatorname{MLP}_{g}([z_{seq};z_{event};z_{graph};a_{seq};a_{event};a_{graph};q_{seq};q_{event};q_{graph}])_m\right),
\quad h_{i,t}=\sum_m g_{m,i,t}z_{m,i,t}.
\]

不可用模态在 softmax 前屏蔽，避免模型给不存在的信息非零权重；信息陈旧度仍提供给 gate，使模型可以下调过旧图关系的权重。融合表示与可用状态拼接后送入 64 维 MLP 和 sigmoid 输出尾部风险概率。训练用加权二元交叉熵，类别权重仅由训练折估计；验证期早停并选参。报告门控权重分布和不同可用性分组下的表现，解释权重只作模型行为分析，不作因果解释。

### 6.5 训练和复现

主预测网络使用 PyTorch；图操作使用 PyTorch Geometric 或等价的稀疏消息传递实现。按交易日批次读取同日公司样本和当日图快照，保持训练、验证、测试日期先后。固定随机种子，至少 5 个种子重复主模型，报告均值、标准差和区块 bootstrap 区间。模型、抽取器、数据切分、特征字段和预测逐样本结果保存版本号、配置和哈希；授权 RESSET 原始文件及公告原文不入 Git。

**单日推断伪代码：**

```text
输入：公司 i，预测交易日 t，已训练好的 Qwen、GRU、GraphSAGE 和门控参数
X_seq ← 最近 60 个交易日截至 t 的收益/因子序列
G_t   ← 只保留 InfoPubDt ≤ t 且当时有效的机构持股边
E_t   ← 只保留公告公开时间 ≤ t 的业绩预告表示和诉讼计数
h_seq ← GRU(X_seq)
h_evt ← TimeAttention(QwenPool(E_t, 最近 20 个交易日))
h_gph ← GraphSAGE(G_t, 当时各公司可得的序列特征)
a,q   ← 各路可用掩码与信息年龄摘要
g     ← softmax_gate(h_seq, h_evt, h_gph, a, q)，对不可用路屏蔽
h     ← Σ_m g_m · Project_m(h_m)
返回：sigmoid(MLP(h, a))  # 公司 i 在 t 后五交易日的尾部概率
```

训练时按第 7 节的扩展窗分别拟合风险分类器；数据标准化、类别权重和早停均只使用对应训练/验证期。测试年只接收预测特征并生成概率，不用于重新拟合公告抽取器、调门控结构或选模型。

## 8. 指标与“提高多少”的报告方式

主指标为 Average Precision（AP，平均精确率，PR 曲线面积的一种计算口径）；不把 AP 叫作准确率。补充 ROC-AUC、Recall@Top 10%、Precision@Top 10%、正类 F1、Brier 分数、校准曲线及每折正类率。业务上 Top10 指按风险分排序后仅审查前 10% 公司日时捕捉到的正例比例，同时报告被捕捉的正例占全部正例比例，避免歧义。

最终增量写成同折配对差：

\[
\Delta AP=AP(M)-AP(B2),\qquad RelativeGain=\Delta AP/AP(B2).
\]

按连续交易日分块 bootstrap（区块至少覆盖五日标签重叠，主分析采用 20 个交易日区块，另报 5/60 日敏感性）估计差值置信区间。按年份展示 ΔAP，防止全期平均掩盖市场制度和正类率变化。只有总体增量方向稳定、主要测试期并非单年驱动且置信区间支持正增量时，才表述为“提高”；否则报告“未观察到统计上稳定的提升”。首轮 LightGBM AP=0.2366 仅为参照点估计，不是最终锁定值。

## 9. 同类研究对照与可比性

| 研究 | 已核实方向 | 与本课题关系 | 为什么不能直接搬用论文报告的指标 |
|---|---|---|---|
| Hou & Liu (2023) | 机构交叉持股与股价崩盘风险 | 最接近持股—崩盘风险关系 | 研究设计、标签周期、样本和预测切分不同；本课题需在本地标签上重跑 |
| Peng、Wang、Gu (2023) | A股年报预判性数字化披露与未来崩盘风险 | 最接近中文文本—A股崩盘风险 | 年报年度主题和年度实证指标不同于公告日频及五日预测 |
| Cheng et al. (2022) | 多模态图神经网络用于金融时间序列预测 | 支持图与多源建模可行性 | 金融序列任务和目标指标不同，不能作为同任务 SOTA 数值 |
| Feng et al. (2019) | 时变关系图股票排序预测 | 支持关系图时序预测路线 | 主要任务是收益/排序，非本研究定义的尾部分类 |
| EFSA (Chen et al., 2024) | 中文财经新闻事件级情感抽取 | 支持标注字段与事件抽取设计 | 新闻文本不等于交易所公告；F1 需在本地公告金标测 |

文献中数字可作为方法背景，不把异数据集 AUC/AP 直接与本课题结果横向排名。正确比较是把相关模型思想复现为本任务的可行基线，在同一标签与时间外样本上重新训练、计算 ΔAP。

## 10. 数据与模型实施流程

1. 锁定原始表文件清单、字段映射、代码映射、日期时点与重复行处理；输出审计报告。原始表始终只读。
2. 复核标签程序、阈值时间可用性、窗口缺失规则和公司日唯一性；保存标签版本及报告。
3. 冻结交易日训练/验证/测试表、purge 日期及统一样本 ID；所有模型共享同一索引。
4. 从现有数据派生 60 日时序输入和公告时点日面板；构造股东机构实体映射表、披露版本流及逐时点图快照。
5. 完成约 200 条试标、冻结规则、扩展至约 1,500 条业绩预告人工数据；训练 QLoRA 抽取器并报告独立测试质量；诉讼公告另构造结构化事件计数。
6. 按预测日缓存公告表示和 GraphSAGE 邻居采样图；先做数据可用时间审计，再训练完整门控网络。
7. 先在统一训练/验证折冻结模型配置；按四个测试期计算主指标、逐日预测和分块区间。
8. 完成标签 P5、行业调整、窗口长度与图边随机化/缺失新鲜度消融；仅对冻结模型做解释和误差分析。
9. 整理模型结果、抽取错误、图覆盖率、资源记录、限制与代码版本，写作并复核报告数字。

## 11. 当前进展、差距和风险

### 已完成

- 标签脚本、数据审计、已有量价特征和首轮 Logistic/LightGBM 比较已在仓库中；面板 6,116,554 行。
- 四个测试期首轮平均 AP：无技能 0.1072、下行波动率 Logistic 0.1307、全特征 Logistic 0.2218、LightGBM 0.2366。
- 数据字段范围和不应泄漏的发布日期规则已有初审。
- 相关研究检索确认：共同持股—崩盘风险、A股年报文本—崩盘风险、多模态金融图预测均有论文先例。

### 尚未完成且影响论文结论

- 首轮基线没有独立时间验证集，也没有日区块置信区间；必须重跑正式协议。
- 公告人工金标、QLoRA 抽取模型和独立质量评价尚未完成。
- 股东实体映射、按发布日期图快照、GraphSAGE 和图覆盖率审计尚未完成。
- GRU、可用性感知门控融合及正式消融还未实现或训练。
- 中文学术文献页码、原文变量和若干英文论文的完整方法细节需要人工阅读全文；当前结论不声称已经穷尽检索。

### 主要风险及预设处理

| 风险 | 可能影响 | 必须执行的处理 |
|---|---|---|
| 公告标签主观、LLM 抽取不稳 | 公告分支噪声会稀释预测信号 | 先试标、双人复核、字段级 F1；下游保留模型输出和原生字段对照 |
| 共同机构实体错配 | 伪造边导致图效果不可信 | GDID 优先，规范化名称人工抽查；报告映射覆盖与错配率 |
| 股东数据低频且披露滞后 | 图信息过时，增益有限 | 将边龄显式送入 gate，并按陈旧度分层报告 |
| 五日标签重叠、市场漂移 | 指标区间偏窄、测试年不稳定 | 日期块 bootstrap、四个测试期单列、边界 purge |
| 大样本图训练资源不足 | 训练耗时、显存压力 | 稀疏采样、按日切片、租用 GPU；处理和训练分离，保留 CPU 表格基线 |
| 组合模型提升不显著 | 不能支持“方法提升”主张 | 仍报告负结果；分析信息质量、覆盖度和分布漂移，不伪造精度 |

## 12. 可行性判断

毕业设计可以用当前数据完成：核心目标、因子标签、量价基线和两类结构化信息都已具备。固定方案的工程量明显高于初等分类实验，但已有明确拆分模块和正式基线，且公告微调可以由用户在租赁 GPU 上单独执行。研究结果不可预先保证提升；可保证的是任务、数据时点规则、对照方法、评价指标和失败时的报告标准在开题阶段已经具体、能检查。
