## 一、需求落实为一项研究，而不是模块堆砌

### 1. 要交付的研究对象

每天收盘，以公司—交易日为单位，预测同一公司未来五个市场交易日的三因子条件左尾事件。使用本地已经存在的收益、因子、业绩预告和机构持股资料；诉讼作为独立结构控制。固定主模型包含60日GRU、Qwen3-8B QLoRA公告抽取、公开时点更新的机构—公司二部图、边龄加权消息及有界残差融合。没有“先省掉图、以后再扩展”的毕业路线。

论文的中心不是“把三个模型拼起来”，而是：**异步披露信息进入日频预测时，怎样限制陈旧或不可靠辅助信息对每日收益主干的修正，并验证这种限制是否有实际价值。**

## 四、核心方法为什么具有研究复杂性

### 1. 问题来自不同更新频率，不是为复杂而复杂

收益每日更新；公告稀疏、抽取可能出错；股东资料低频且公告日晚于报告期。三路向量直接拼接不能自动保证未来信息未进入，也不能约束缺失或过时信息的修正。披露对齐是可信实验的必要条件，年龄包络是待检验的归纳偏置，二者不能混称“创新”。

### 2. 固定可证明的融合性质

对辅助路m：

`a_m = M_m Q_m exp[-softplus(lambda_m) A_m] sigmoid(G_m)`

`delta_m = tanh(z_m)`

`z = z_s + a_e delta_e + a_g delta_g`。

因为sigmoid在(0,1)、|tanh|≤1：

`|a_m delta_m| ≤ M_m Q_m exp[-softplus(lambda_m) A_m]`。

因此辅助路修正幅度有显式上界，全辅助缺失时严格回到同一个已训练模型的z_s；年龄增大时上界缩小。进一步，由sigmoid导数不超过1/4，可得到分数概率偏移的保守界：

`|sigmoid(z)-sigmoid(z_s)| ≤ (a_e+a_g)/4`。

这些是结构性质，不是泛化性能定理。主干参数本身受联合训练影响，所以缺失回退不代表等于另外训练的GRU基线。预测概率也不必随年龄单调；门和内容仍会改变修正。

### 3. 图路必须真正含跨公司信息

边权固定为总股本比例乘边龄衰减。针对公司i通过机构j接收的消息，机构聚合应剔除公司i自己的贡献：

`u_(j\i) = sum_(k≠i) v_kj phi(s_k) / sum_(k≠i) v_kj`。

再按i的持股边权聚合`psi(u_(j\i))`，与自身序列拼接投影。当机构只连接i时，这条边不能产生关系信息；无共享机构邻居时M_g=0。可用性按共享邻居判定，不按“存在机构持股”判定。

这个处理用于防止序列信息经自回路被误记成关系增量，不单独宣称新的GraphSAGE算法。归一化加权均值会抵消组内统一衰减倍数，所以不能声称所有旧消息一定等比例缩小；边龄调整的是相对贡献，最终logit上界由残差包络控制。

### 4. 文本训练与风险训练明确分离

800条2017—2019训练、200条2020验证、500条2021—2024-07独立测试，共1500。200试标从800条训练样本中取，300双标从1500条中取。抽样只依据年份/来源预测类型，不依据未来尾部标签。跨集合修订家族排除出金标池，但仍按公开时间进入风险面板。

Qwen训练监督是经营/财务方向、原因、原文证据，不是股价方向。初始固定4bit NF4、rank16、alpha32、dropout0.05、batch1、梯度累计16；`max_length=2048`是系统+用户+答案的总长度上限，正文预算起始1024token，二者不能混用。当前训练脚本遇超长整条跳过，正式运行必须报告被跳过数量和类别，统一比较集；不能称已有完整正文截断/缓存程序。

完成验证选模后冻结Qwen。按原文、基座revision、adapter、模板、正文token范围和截断策略哈希缓存正文隐藏状态及模型预测字段。风险模型的事件投影、GRU、图消息和融合联合训练；不得缓存随机GRU或图隐状态冒充学到的特征。

现代Qwen预训练晚于历史预测期，论文是回顾性表示研究，不是证明2017年可部署。匿名控制不等于证明没有预训练记忆。

### 5. 规模与计算复杂度

设日公司数N、序列长度T=60、事件上限K=8、机构边数E、隐维h=128。GRU约O(NT h(h+F))；事件投影约O(NK D h)，D是冻结文本原始维度；二部消息可用稀疏求和完成，约O(Nh²+Eh+Eh²)，不必构造N×N稠密公司图。去自身聚合复用机构总和再减自身，不遍历每条边的全部邻居。

计算与数据产品、算法约束、近邻对照、人工抽取评价、时序统计形成一项完整研究。这足以构成有深度的硕士工作范围，但学校是否认可须由导师/学院评审；不能由代码行数代替学术判断。

## 五、实验合同：每张表回答一个问题

### 1. 固定输入信息的层次

- R：历史收益/因子、历史尾部统计、有效率，全部只看t及以前。
- N：原生业绩预告类别/幅度/利润区间、事件数和年龄、诉讼结构控制。
- E：Qwen预测三字段及冻结正文向量。
- G：公开时点机构图、覆盖/度数/集中度/边龄及邻居历史特征。

强表格“同信息”不能只给几个方向计数，而主模型独享正文向量。表格对照必须获得相同事件聚合向量：高维部分以每折训练期拟合PCA至64维后与结构字段合用，验证/测试只做transform；另报仅结构字段版本。原始信息一致，不意味着树和GNN表示能力一致，必须写清可访问输入与变换。

### 2. 固定模型与执行数量

| 组 | 内容 | 正式训练 |
|---|---|---|
| 树模型仅R与R+N+E+G | LightGBM、XGBoost、CatBoost；每类每信息组最多8组验证配置 | 3×2×4×8=192候选上限；每折各类选定配置的同信息树模型均跑5种子，3×4×5=60次预算上限；总主对照从全部同信息模型的验证种子均值选 |
| 可解释参考 | 11字段Logit、传统风险统计Logit | 各4折，固定参数或训练/验证选择 |
| 主要神经组 | 仅R的GRU、相同编码器拼接、普通门控、MSGCA式适配、M | 5×4×5=100次；同信息组共享固定诉讼控制 |
| 直接图方向对照 | Graph WaveNet任务适配、专利摘要启发式多关系适配 | 2×4×5=40次；注明改造点与不可忠实复现部分 |
| 机制/信息消融 | 去事件、去图、去年龄、年龄无指数包络、去质量、去辅助损失、仅去边衰减、随机图、仅原生字段、仅Qwen结构字段、匿名文本 | 11×4×5=220次 |
| 标签稳健性 | P5下M与验证选定的同信息对照、普通门控 | 3×4×5=60次 |

约420次锁定配置的神经/P5运行，另加神经验证选参、树候选、对照重训与Qwen抽取。若18个P10神经/消融组各折以种子42多试一个学习率，则额外72次；P5三组同样试参再加12次。候选阶段通过验证后才生成冻结测试预测，不把额外选参成本藏进420次。这个预算不小；要在小规模计时后确认租赁时长，不能给一句“单卡可完成”就结束论证。图覆盖与年龄分组、日期块长度、校准、误差分析尽量从冻结预测计算，不重复训练。若有任何模型未跑，登记未完成，不删表伪装完整。

只在验证年搜索学习率{3e-4,1e-3}，最多20轮、连续3轮无改善早停。主比较配置/输入选择不按测试结果改变。全程使用相同公司日索引，不因公告或图缺失删样本。

### 3. 指标、种子和区间的具体统计量

每折每种子计算AP。主统计量是四折等权的种子平均AP，而非先平均预测概率的集成AP；集成只能附报。主对照从树模型与神经架构等全部已登记同信息对照中，按该折验证种子平均AP选择（排除M）；不能只选树模型，也不按测试AP选择。

`Delta = (1/4) sum_f [(1/5) sum_s AP(M_fs) - (1/5) sum_s AP(B_fs)]`。

评价入口通过`--seed-models`和`--seed-baselines`分别支持双方的种子列，先计算每折每种子AP再平均，不平均预测概率冒充AP均值。只给一列对照时，CI条件于该固定对照；主实验使用双方全部五种子。CLI已具备这个统计量，但训练矩阵、主对照登记与预测合并器仍需实现。

在每折内部按连续市场日期切成不重叠20日块，所有公司一起重采样，折与折不拼接。每个重复先算各折差，再等权平均；1000次，5/60日敏感性。当前代码使用块出现次数作为sample_weight，等价于复制整块公司日，不把数据重复拼成巨大的DataFrame。CI表示样本时序不确定性，种子标准差另列。测试期未抽取的间隔、缺日期必须在日历审计中解释。

每日Top10为当天ceil(0.1N_t)公司，证券代码破同分；报告日精确率和有正例日期的日召回均值。正类F1的阈值只在验证选择。校准也仅在验证拟合，未校准分数不声称精确概率。

### 4. 五组论文核心结果表

1. 标签/样本流失/模态覆盖/年龄表：说明信息集是否可信。
2. 人工一致性、规则、Qwen零样本、QLoRA抽取表：说明事件编码是否有效。
3. 四折完整主比较表：同样本、输入权限、种子、AP/ΔAP/CI、每日Top10、Brier与资源。
4. 消融表：分别解释信息、约束、边消息、质量的作用。
5. 误差/漂移/覆盖分组表：说明哪些情形有效，哪些没有改善。

已有先导Logit0.221784、LightGBM0.236579的差1.48个百分点只属于旧表格结果。M的提升数保持“待正式训练”。

## 六、可完成性门槛与成本核算

### 1. 四个必须前置的放行点

| 门槛 | 验收 | 不通过时如何处理 |
|---|---|---|
| Gate-D：时点数据 | 字段映射完整、公开版本/名单类型可解释；抽查无提前生效；所有未知版本组有排除/限制记录 | 不把不明组设complete=True；不得伪造图，登记限制并取得原公开版/词典或停在未放行状态 |
| Gate-A：人工标注 | 1500裁决、300独立双标、试标子集与金标年代正确；报告分歧、覆盖和证据错误 | 补标/裁决；不能让LLM自标替代金标；低Kappa不删难例 |
| Gate-G：设备和吞吐 | 单卡实测QLoRA、正文缓存及真实日图训练，显存/内存低于可用量且有余量；总预算可排进剩余时间 | 在固定全部模块下缩短正文/分块/增加租赁时长，记录配置；不能直接去掉模块 |
| Gate-R：正式结果 | 输入和配置冻结、四折/五种子/主对照/消融结果齐全、指标可追溯 | 标记未完成；若ΔAP的CI跨0，报告不稳定增益，不更换测试期 |

日期对齐不等于历史数据库版本真实。UpDt是更新时间，不自动等于首次公众可见时间；SHSer是“股东序号”，不是已经确认的名单类别。不得未经词典解释把它作为整份名单组键，否则可能一行一组。来源、名单类型、排名、修订证据必须共同确认。若只有今天数据库里的修订版，主张应限定为“按记录公开日对齐的回顾性研究”；不能写成完全复原当年的信息集。

### 2. 人工预算可计算，但当前吞吐待实测

第一人1500条、第二人300条；试标已经计入1500。设平均每条v分钟，争议比例d、每条裁决c分钟，则：

`H = (1800*v + 300*d*c)/60`。

举例仅作预算：v=5、d=0.3、c=5时约157.5人时；加20%复核余量约189人时。不能把这些示例当作实测工时。先以200条记录时间，按实际吞吐重排日程。

### 3. GPU与风险训练预算

Qwen是一次抽取器训练，随后对去重事件一次缓存；不会在420次风险训练中反复加载Qwen。缓存合格池在本轮抽样审查为118,504条（只代表可抽样事件，不等于所有风险事件）；若D=4096且fp16，单份正文向量约0.90GiB，实际D由模型config确定，匿名/零样本等缓存份数另计。

全量60日序列不重复展开为600万份；以原始日面板索引在线取窗。仅把600万×60×5个float32物化就约6.8GiB，已经超过当前余量；如果每个公司日还重复8个事件高维向量，代价更大。应保存事件表+引用ID、图披露流+版本索引，按日期装配。当前训练入口只读NPZ，正式共享索引适配器仍需开发，不能假称这些优化已经实现。

风险训练总时间：

`T = sum_runs [epochs_run * train_day_batches_run * seconds_per_batch_run + validation/inference time]`。

加Qwen训练、缓存、候选树、IO、统计与失败重跑；预留至少30%。必须以真实512/2048公司日试跑、代表性低/高边数日、原始文本维度记录吞吐。当前CPU合成测量：512公司约1.92秒/步、峰值RSS511MiB；2048公司约2.90秒/步、RSS914MiB，各3步且波动明显。测量并行于原始数据加工，不能据此线性外推GPU小时或全市场训练时间。

GPU起始设备24GiB；是否足够以测量为准。没有指定GPU预算上限，因此租赁费用待确认，文档不填写未获授权的付费数额。学校截止日同样待学院通知核实；2027-02-07是现有交接的初稿目标，不当作已核实的送审日。

## 八、CCF-B投稿的判断，不是录用承诺

这项工作的硕士完整性来自一条闭合研究链；CCF-B竞争力还要求新的方法问题值得一般研究者关注。仅将Qwen、GRU、GraphSAGE、时间衰减和sigmoid组合起来，通常不足以支持高质量方法论文。

潜在论文叙事固定为 **年龄约束的辅助残差学习用于异步披露的尾部预测**。需要证明：

1. 最接近MSGCA及近期LLM关系融合没有覆盖本研究同样的年龄包络与评价问题；完成全文/专利/学位论文逐项核验。
2. 在相同信息、同编码器、可比预算下，M优于普通年龄特征、普通门控和MSGCA式适配，不只胜过弱Logit。
3. 多折方向一致，主ΔAP的配对块CI支持正增量；关键机制消融有一致解释。若统计证据不足，不能靠表述强化成方法优越性。
4. 年龄与噪声压力测试给出修正控制的实证作用；自然陈旧年龄分组和人为增龄压力分开报告，不改变主测试样本。
5. 有数据泄漏、版本覆写、现代预训练和机构错配的严肃审计；提供合法可发布的代码及不含授权正文的结构/合成复现材料。
6. 方法改善在多个年份与P5设置可复核；当前单市场结果不等于跨数据集泛化。若投稿场合要求额外数据集，属于投稿门槛而非偷偷加入当前毕设主线。

**结论：可以按CCF-B投稿标准准备，但当前没有数据和结果足以断言“已经达到CCF-B”。** 某些财务/机器学习期刊是否属于CCF-B，必须查相应年度官方目录；本轮官方页面访问受限，没有核准分类，不把搜索结果中的期刊级别直接写入结论。完成主实验后，由真实增量、近邻区别和目标征稿范围决定是否投稿；毕业进度不绑定审稿录用。
