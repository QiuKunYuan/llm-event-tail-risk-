# 历史方案归档说明

本文件此前保存了多个候选题目、可选模块和未经核实的性能/创新表述，已不再作为当前方案依据。为避免旧内容与用户现已确定的“完整、固定、可比较”研究范围混淆，详细历史方案已从本入口撤下，Git 历史仍可查阅。

当前固定研究设计见[完整毕业设计研究设计报告](实施版研究设计.md)，正式开题正文见[开题报告正文（确定方案）](../开题报告/开题报告正文-确定方案.md)，研究现状及论文核验见[同方向文献核验与题目论证](../开题报告/同方向文献核验与题目论证.md)。

当前题目：**披露时点感知的A股短期尾部风险预测**。

固定主线包括：日收益 GRU、Qwen3-8B QLoRA 公告事件抽取、按信息发布日期更新的共同机构持股图、GraphSAGE、可用性与披露陈旧度融合。强基线固定比较传统尾部特征 Logistic、LightGBM/XGBoost/CatBoost、改造版 Graph WaveNet 和 MSGCA 式三模态门控，并做单模态、简单拼接和时点门控消融。预测对象是公司自身未来五个交易日的条件异常下跌标签。
