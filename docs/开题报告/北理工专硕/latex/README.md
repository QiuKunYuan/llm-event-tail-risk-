# 图文开题报告 LaTeX 工程

本工程是主要开题正文，不是PPT。题目为**基于多维时序数据融合的短期证券市场风险预测**，邱琨原，北京理工大学两年制专业学位硕士，采用学校七栏目和研究生 `type=master` 封面。

## 本次研究设计

主目标为未来五个**市场**交易日实际收益复利积减一，不扣市场、行业或因子。四档为非亏损、普通亏损、较大亏损（不高于-5%且大于-10%）、严重亏损（不高于-10%），由共同分布得到嵌套的 `p_loss / p5 / p10`。Dret总回报语义、时点上市总体、日交易估值及终端价值尚需认证；预测总体不由未来完整窗口筛选，结果左连接并保留未知原因。

新增真实CPU来源子集核查为61个请求历史日期、111,758条冲突证券行：DRET市场收益候选每日不一致，不能任取或平均成市场序列，需官方市场/指数与EXCHANGE、MARKET身份说明；FF3的2|A筛选也未认证其全A股范围。行业4,393行、状态2,971行的原字段已恢复，原7/6列全行字面保持；不重复导出这些字段，历史有效区间仍未认证。这些不是全2329日期核查或监督模型结果，完整新候选/索引统计仍待独立核验。

方法采用个股64/市场32/行业32维掩码GRU的128维价格上下文、上下文query事件选择、显式邻居价格+事件状态去自身消息，以及可靠性约束的四档概率混合。主方案只有混合NLL、匹配模态dropout与正则。验证1—8月选参，9—12月独立校准最终四档和绝对预警阈值，所有边界按结果结束日purge。四个测试折2021/2022/2023/2024至7月24日、五种子，采用强同信息对照与真正重叠移动日期块。

市场/行业平均p5、p10是预期损失成员占比，不是指数崩盘概率。全总体未知结果报告实际广度界限；每日Top10%仅次要容量指标。原残差标签、组候选和先导AP数字保持真实历史定义，不改名为新结果。没有预计性能图。

## 源稿与图表

- `main.tex`：专业硕士封面、目录、正文、参考文献和正文页数标记。
- `sections/`：学校七栏目连续正文。
- `methods/`：实际损失与事件、共同价格、关系概率混合、实验与工程设计。
- `figures/figures.tex`：22幅原创TikZ/PGFPlots图，其中源聚合图为真实历史事实，年龄权重和旧logit帽为注明条件的数学示意，其余为设计图。
- `data/audit-summary.json`：历史聚合与真实就绪状态，不含授权源行、样本预测或人工答案；新候选数未由旧统计推算。
- 构建器生成 `references.bbl` 与两个聚合 `.dat`。参考文献复用独立综述维护的34条题录。

正文源含28,054个CJK字符（不含封面、图程序、参考文献）；独立综述正文5,493个CJK字符（另排除姓名、培养类型与题目元信息）。字符数不是页数证明，页数必须实际编译。图表三色蓝/橙/绿已用dataviz验证器对白底执行all-pairs CVD检查，全部通过；绿色对比2.82:1，由黑字直接标签、图例和关系虚线框提供额外辨识。数值图有正文数值表，单一序列不加冗余图例。PDF为静态文稿，不需要网页hover或暗色模式。

## 构建与验收

用户原样板ZIP留在私有目录，SHA256为 `21ab1e018f9fcb9bf522d9d508e88b4d65697e688980ca31dfb94e8fa6cd51e6`。构建只提取其未修改、docstrip生成的BIThesis 3.7.4类；不使用原本科正文、字体、图片、签名或旧个人信息。中文使用Noto CJK或Fandol，英文使用TeX Gyre Termes。正文小四12bp、22bp行距保持原有正常设置，不通过放大字号、空白或重复综述凑页。

Debian/Ubuntu依赖为 `texlive-xetex texlive-lang-chinese fonts-texgyre texlive-fonts-recommended`，后者提供hyperref需要的 `pzdr.tfm`。构建目录必须在Git仓库外且首次不存在：

```bash
python3 scripts/build_long_proposal.py \
  --template-zip /private/path/论文Latex.zip \
  --build-dir /private/path/new-actual-loss-proposal
```

准备输入用 `--prepare-only`，恢复同目录编译用 `--use-prepared`。构建器三次调用XeLaTeX并禁用shell escape；要求**实际正文至少30页，不含封面、目录、参考文献**，拒绝未解析引用、缺字以及hbox/vbox溢出。页数通过之后还要实际渲染并全页检查图、公式、文字、页码和留白。

对当前源的渲染页完成审阅后加 `--publish --visual-reviewed` 生成当前图文PDF和净源码ZIP；该声明是调用者的实际审阅记录，编译器不代替视觉检查。已有输出只有确认更新时才用 `--overwrite`。源码ZIP采用精确白名单，只含13份自写TeX、历史聚合JSON、两个生成聚合dat、生成引文、README/许可说明和原字节类依赖。任意私有构建目录中的额外JSON、原行、图片、字体或签署文件均不打包，原类被修改则拒绝发布。

本轮已实际三轮编译并完成61页全页渲染与图、公式、引用和版面检查：单页封面，4页目录，**52页正文**（PDF物理第6—57页），4页参考文献。末轮日志在正文开头及七章末均为12bp字号、22bp行距，没有重复叠加模板1.53倍行距；PDF正文行坐标另行核对。未解析引用、缺字、hbox/vbox溢出均为0。正文无空白填充页，22幅图实际入稿。测试命令：

```bash

```
