## 怎样讲

主讲净时按逐页建议合计680秒，即11分20秒，另留翻页和停顿，约12—13分钟。第19—22页不计入主讲，老师问到标签、统计、图身份、LLM污染或创新时再翻出。学院规定时长优先，排练可调整语速和讲述深度，不代表删减论文主线。

|---|---|---|
| 1—4 | 身份、实践问题、预测标签与近邻 | 一 选题依据 |

## 验证与显示

PPT正文与表格使用微软雅黑，普通正文至少17pt，标题28pt；出处、图例、定义等附注使用较小字号。三支路颜色固定为收益蓝、公告橙、关系绿，始终配S/E/G直接文字和图例，色彩不单独承担含义。配色已运行色觉/明度检查，绿色小标记的低对比以黑色直接标签和图例补足；正文黑色和灰色文字对比度分别约19.17:1和7.73:1。

包内22页与22份备注、对象边界、讲稿标题/时间、协议和事实快照均做程序检查；所有页面生成联系图查看，结构图、公式、表格等关键页另作放大抽查。Linux LibreOffice渲染不等于Microsoft PowerPoint/WPS全面显示验收。填入长导师/学院名称或切换字体后，需在答辩设备再检查版式、公式符号和播放顺序。

## 再生成

本仓库默认`generate:proposal`现生成学校版，不再默认生成旧技术稿。先审阅现有PPT，再显式覆盖：

```bash
npm install
npm run test:presentation
npm run generate:proposal -- --overwrite
```

原技术稿仍可通过`npm run generate:proposal:legacy`重建，属于历史入口。不要运行旧入口后，把新生成的旧稿当作学校版。学校版生成器从逐页Markdown讲稿读取备注，源文件为`scripts/generate_bit_opening_ppt.js`；配色和界限检查不替代真实渲染。
