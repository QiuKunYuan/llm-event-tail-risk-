# 同方向研究核验、题目论证与创新边界

> 检索记录日期：2026-11-23。本文使用 Crossref DOI 元数据、ACL Anthology、期刊 DOI 入口及高校/作者单位介绍页核对可见书目信息和摘要。当前核对足以确认存在直接相关工作，但不等于完成系统综述，也不代表已阅读全文核对所有变量、样本筛选及稳健性表格。

## 一、结论先行

1. **同方向研究确实存在。** Hou 和 Liu（2023）直接研究“机构交叉持股与股价崩盘风险”；彭俞超、王南萱、顾雷雷（2023）直接研究 A 股年报文本披露与股价暴跌风险；Cheng 等（2022）研究多模态图神经网络金融时间序列预测。这三条文献分别覆盖本设计的股东关系、文本风险及金融图预测部分。
2. **本课题不能宣称“首次将文本/GNN/共同持股用于风险预测”。** 这些部件各自已有先例，且前两项与本研究的经济问题很接近。
3. **可成立的论文定位是具体预测设定和联合方法的实证检验。** 重点是公司日频未来五日尾部分类；公告与持股网络按真实公开时点对齐；模态门控读取公告是否出现和持股信息陈旧度；与一致样本上的表格、GRU、单模态、简单拼接模型作成组比较。
4. **创新强度需谨慎评价。** 这是学位论文可验证的方法应用/组合创新，不足以在尚未系统查重和阅读全文前宣称理论首创。最终需要用同任务基线的样本外增量来支撑价值，且可能得到“没有提升”的结果。

## 三、对“提高多少”的正确回答

已发表论文中的 AUC、AP 或回归系数不能直接横向比较，因为它们可能使用不同国家、样本期、标签频率、正类定义、股票筛选和数据切分。本项目已经有自身可复核的首轮参照：四个测试期平均 AP 为无技能正类率 0.1072、60日下行波动 Logistic 0.1307、全特征 Logistic 0.2218、LightGBM 0.2366。它是试跑值，尚无正式独立验证期和日期区块区间。

正式回答“提高多少”采用完全相同测试公司日上的配对差值：

`ΔAP = 完整模型 AP − LightGBM 同样本 AP`

同时报告相对增幅、年度单折差值、Top10%风险名单召回、Brier 与区块 bootstrap 置信区间。只有测试期表现没有被单一年份驱动，且差值区间支持正增量时，才写作模型显著改善排序。否则如实写没有观察到稳定改善。不能在开题报告里承诺“提升 x%”或百分之百成功。

## 四、为何基线采用这组方法

- **正类率参照**回答模型是否超出无排序信息的基本水平；标签约 10.94%，但 AP 应以每个测试折实际正类率计算。
- **Logistic**是结构简单、可解释的传统参照，用同一 11 项既有量价/因子输入。
- **LightGBM**是表格数据的重要非线性强基线，已有试跑 AP 0.2366；它是主要主张对照，避免把复杂模型和过弱方法相比。
- **XGBoost**提供第二种梯度提升树参照。
- **GRU、GraphSAGE 单支路**检验深度时序和关系图各自能否提供增量。
- **简单拼接/固定权重**是门控机制的必要消融，判断提升是否来自动态可用性感知，而非仅仅增加特征容量。
- **时点感知门控完整模型**是新设计；所有对比均用同标签、共同日期和固定切分重新运行。

因此论文的“与已有方法比较”由两部分组成：研究现状中按原论文任务和结果作定性定位；实证部分在同一数据和同一预测定义上复跑可复现基线。不能把跨论文的异任务准确率冒充公平比较。

## 五、题目论证

### 最终工作题目

**时点感知门控融合的A股尾部风险预测**

题目把篇幅留给方法焦点“时点感知门控融合”和研究对象“A股尾部风险预测”。公告事件、共同机构持股、GRU/GraphSAGE、Qwen3-1.7B 是正文中的具体输入与实现，不全部塞进题名。题名不声称因果传染，也不写宽泛的“研究与应用”。

### 一句话解释

每天收盘后，用截至当时的市场历史、当天以前已公开的公告语义和最近已披露的机构持股关系预测公司未来五个交易日的异常下跌风险；门控根据公告是否有新信息和持股图有多旧，调整三类信息各自的贡献。
