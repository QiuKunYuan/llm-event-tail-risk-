# 同方向研究核验、研究边界与强基线设计

> 检索日期：2026-11-23。本文用 Crossref、OpenAlex、Semantic Scholar、ACL Anthology、arXiv、出版社页面和公开中文网页检索核对可检索的论文题名、出版信息、摘要及专利线索。当前已发现多篇高相关工作，故本课题不宣称“首次使用 LLM、图神经网络或门控融合”。检索覆盖不是系统综述，也无法证明没有未发表学位论文、在审稿件或企业内部研究采用相近方案。

## 一、检索结论：有明显近邻，不能把通用架构当作创新

现有草案把收益序列、公告文本、股票关系图和可用性感知门控组成三模态网络。文献核验发现：

1. **股票崩盘风险预测已有图学习先例。** Jing 等（2024）题为 *Predicting Stock Price Crash Risk in China: A Modified Graph WaveNet Model*，直接以中国股价崩盘风险为任务。
2. **三模态股票预测和门控融合已有几乎同构的先例。** Zong 等（2025）的 MSGCA 同时编码指标序列、动态文档和关系图，以门控交叉注意力融合。这与草案的“收益序列＋公告＋持股图＋门控”在高层方法上高度相似。
3. **LLM、多关系图和动态融合股票预测也已有新近论文。** Yi 等（2026）的 *Financial LLM-enhanced multi-relational dynamic fusion for stock trend prediction* 将金融 LLM、多源文本/价格、长期关系和短期关系动态贡献融合。论文在线发表于 2026 年，属于必须纳入的近邻工作。
4. **国内已有直接面向股价崩盘风险的多关系图神经网络专利。** 中国专利 CN117808586A《基于多关系重构与融合图神经网络的股价崩盘风险预测方法》于 2024-04-02 公开。可检索摘要披露了时间序列编码、显性/隐性关系重构和多关系融合图神经网络，预测上市公司股价崩盘风险。这与当前方案的“风险目标＋时序＋关系图”重合明显，是目前发现的高风险近邻；当前可见摘要没有说明公告事件文本、真实披露时点或边龄门控。专利全文及权利要求尚未核验，不能把这些摘要未提及的部分当成已确认差异。
5. **机构网络与崩盘风险、文本与崩盘风险分别已有直接研究。** 因此，机构持股图、公告文本或 Qwen3-8B 单独都不能作为首创点。

截至当前，公开检索尚未命中一项可以确认与本设计全部细节完全相同的研究，但已发现针对同一风险目标、并结合时间序列和多关系图模型的中国专利，以及高度相似的三模态门控论文。因此，当前方向**不能被表述为“没有人做过”或“已确认不重复”**。本方案可辩护的区别暂时仅是：公司日频五日公司特有因子残差 P10 标签、公告/持股真实公开时点重建、信息可用性与披露年龄门控，以及统一同样本时间外检验。CNKI、万方学位论文、校内论文库和专利全文/权利要求仍未完成系统核查；在导师确认前，创新性属于待核验而非既定事实。

### 对题目与创新表述的调整

工作题目统一为：

**披露时点感知的A股短期尾部风险预测**

题目突出可区分的预测设定，不把“门控融合”写成原创算法。论文定位为：在公司自身未来五日尾部事件预测中，按真实披露时点重建可用信息，评估公告事件与共同机构持股关系对历史收益基线的增量，并检验按信息年龄和缺失状态调节信息贡献是否有用。门控/GNN/LLM均有先例；可能成立的贡献是**特定目标、时点数据流程、信息年龄处理和严格同样本实证检验的组合贡献**，需要实证结果支持，不是理论首创承诺。

若导师认为与 CN117808586A、MSGCA 或 2026 年金融 LLM 多关系融合论文仍过于接近，开题前应先调整研究问题或核心方法，不能靠换数据集或换中文题目掩盖方法重复。尤其是 CN117808586A 已覆盖“股价崩盘风险＋时间序列＋多关系融合 GNN”；当前方案只有在披露可用时点/新鲜度机制确有差异、全文核验支持且同样本对照显示增量时，才有应用性区分依据。

## 三、强基线：直接回答“比谁好、提高多少”

论文中的“已有方法比较”分成两类，不能把异数据集论文的准确率/AP直接并排。

### A. 同一数据、同一标签、同一日期的预测基线

主预测样本是统一的公司—交易日索引。所有模型使用相同滚动时间折、purge 日期、训练期信息、测试行和主指标。公告或图缺失由缺失掩码表达；另报告公告/图共同覆盖子样本，避免删行造成虚假增益。

| 层次 | 必须比较的方法 | 比较目的 |
|---|---|---|
| 无技能参照 | 测试折正类率/随机排序 | 确认 AP 至少超过标签基率；无排序能力基线的 AP 等于测试正类率。 |
| 传统风险参照 | 下行波动率 Logistic；加入历史残差偏度、DUVOL、残差波动、最大回撤等可由已有收益构造的崩盘风险特征的 Logistic | 与传统公司风险预测特征比较，排除模型只复用近期波动信号。 |
| 强表格模型 | LightGBM、XGBoost、CatBoost；同一套量价、因子和传统尾部特征，仅在验证期调参 | 形成可靠的非线性基线。按每折验证期确定的最强表格模型作为核心比较对象，不按测试集选赢家。 |
| 序列模型 | GRU 单支路 | 判断序列编码是否胜过表格滞后统计特征。 |
| 直接相关图风险模型 | 改造版 Graph WaveNet，输入和标签改为本研究可用的数据与目标 | 对照 2024 年中国股价崩盘风险图时序模型思路。 |
| 近邻多模态方法 | MSGCA 式“价格序列＋公告文本＋关系图＋门控交叉注意力” | 对照已发表的近似三模态架构，避免把通用门控结构作为新方法。 |
| 本研究方法 | 同样的三类信息，加真实披露时点、可用性掩码及图边年龄条件 | 检验新增时点可靠性信息能否改善相对 MSGCA 式融合和强表格基线的样本外排序。 |

逐块消融固定为：量价基线 → 加 RESSET 原生公告字段 → 加 Qwen3-8B 抽取字段/事件表示 → 加共同机构关系 → 三模态普通拼接 → MSGCA 式交叉门控 → 加可用状态/信息年龄。本设计不在实验后变换基线或主指标。

### B. 公告抽取器基线

Qwen3-8B只是事件抽取器，不是尾部风险预测器。对同一人工测试集至少比较 RESSET 原生结构化字段/规则、Qwen3-8B零样本或少样本、Qwen3-8B QLoRA。报告方向分类 Macro-F1、原因与证据的字段级 Precision/Recall/F1、严格 JSON 合法率和证据原文命中率。主预测器的 AP 增量另算，不能用抽取器 F1 替代风险预测效果。

### C. 统计可比性协议

- 主指标：AP；辅助指标：ROC-AUC、Brier、校准误差、Precision@Top10% 和 Recall@Top10%。不使用单一 Accuracy 掩盖约一成正类率。
- 增量：同折同公司日的配对 `ΔAP = AP(本研究模型) − AP(验证期选定的最强比较模型)`。同步报告每年差、绝对与相对增量。
- 五日标签有重叠；按交易日分块 bootstrap 估计置信区间，并报告不同块长敏感性。测试年不用于选择模型、超参数、门槛或报告口径。
- 首轮 LightGBM 平均 AP 0.2366 是先导值，不是最终强基线。CatBoost、XGBoost、Graph WaveNet 与 MSGCA 尚未在本地统一标签/切分上运行，不得提前填写结果。

## 四、题目、问题与创新边界

### 工作题目

**披露时点感知的A股短期尾部风险预测**

### 研究问题

在交易日收盘时，只输入该时点之前已经公开的公司收益、公告和机构持股信息，能否识别公司未来五个交易日的公司特有异常下跌？公告/持股数据覆盖和新旧程度变化时，显式利用可用性与披露年龄是否比普通三模态门控提供稳定的样本外增量？

### 可检验贡献

1. 以公司自身的未来五日因子残差累计值相对历史 P10 定义短期尾部事件，和年度 NCSKEW/DUVOL 崩盘代理及一般涨跌方向任务分开。
2. 按公告公开日和股东信息发布日期构建预测时点信息集，不以报告期末日回填；将公告缺失及持股边龄留在模型可见的输入内。
3. 在完全一致的公司日测试样本上，把本研究机制与传统风险特征、强树模型、Graph WaveNet、MSGCA 式多模态融合及逐块消融成组比较。

以上是拟检验的问题设定、时点处理和适配方法，不是已证实的原创贡献。CN117808586A 已经在股价崩盘风险任务中结合时间序列和多关系融合 GNN；MSGCA 已有指标序列、文本、图与门控融合。即使暂未找到所有细节都相同的单篇研究，也不能据此声称“研究方向无人做”或“国际首创”。开题前须核查专利全文/权利要求、CNKI、万方和校内学位论文库，并由导师评估当前区别是否足够；若导师要求算法层面的明显原创，本课题需先重新选题或重新定义核心方法。
