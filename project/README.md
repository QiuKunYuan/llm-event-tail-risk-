# 毕业设计项目实施目录

本目录保存数据处理、公告标注/QLoRA 训练和项目进度材料。固定研究设计及开题交付入口见仓库根目录 README。

本项目必做模块：滚动尾部标签与时点审计、传统量价基线、60 日收益 GRU、Qwen3-8B QLoRA 公告抽取、按 `InfoPubDt` 更新的共同机构持股图、GraphSAGE、可用性和持股披露年龄门控融合、统一时间外比较与消融。强基线包括传统尾部风险特征 Logistic、LightGBM/XGBoost/CatBoost、改造版 Graph WaveNet、专利启发式多关系时序 GNN 和 MSGCA 式三模态交叉门控；这些结果尚未在本地完成，不能当成已有实验数字。公开检索还发现 CN117808586A 已把时间序列、多关系图神经网络用于股价崩盘风险，构成高重合近邻；专利权利要求及中文学位论文查重未完成，因此暂不能声称研究方向不重复。
