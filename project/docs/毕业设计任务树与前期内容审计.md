## 当前优先顺序与需要用户配合的内容

1. **本周先完成开题报告可审阅初稿。**需要用户提供学校开题模板和导师对题目/研究重点的具体意见；没有模板时先按现有结构写，再迁移到学校模板。
2. **公告模型目前卡在人工金标。**主标注者填写本地 `project/outputs/annotations/earnings_pilot_300_annotator_a.csv`；第二位标注者独立填写 `project/outputs/annotations/earnings_pilot_060_annotator_b.csv`。不需要把 RESSET 正文粘贴到聊天或公开仓库。
3. **暂不要求补导新数据。**当前研究范围用现有数据完成；如果导师要求扩大到 2025 年、加入换手率/市值，再重新评估 DRESSTK 等数据是否必要。
4. **GNN 排在股东图审计之后。**先证明图关系可按披露时点构造并有基本信号，再由 Codex 写训练代码，用户在租用 GPU 上运行。

- `docs/数据核查/RESSET数据导出说明.md` 和旧开题方案中的下载清单是历史盘点，不代表当前必须下载。
- 研究现状初稿只作写作底稿，未经原文核对的文献数字和结论不得直接写进提交版。
- 任务树状态只在验收产物形成后更新；写了脚本但没有输入数据、运行结果或质量评估时，不算该研究模块完成。
