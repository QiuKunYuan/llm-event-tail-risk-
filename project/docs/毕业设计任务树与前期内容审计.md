# 毕业设计分层任务树与逐项验收

题目：**披露时点感知的A股短期尾部风险预测**。更新：2026-11-24。数据验收详见[CPU验收报告](../../docs/数据核查/CPU数据验收-2026-11-24.md)。

状态含义：**已验**有本轮实测产物；**已有待复验**是过去产物；**原型**只通过功能测试；**待做**没有满足验收；**外依赖**需人工/GPU/文献权限。不得把原型写成金融实验完成。

## 一、聚合关系

```text
L0 文件/日历/字段/环境
 └→ L1 标签+四折索引 ───────────────────────────┐
     L1 公告金标 → L2 Qwen抽取/正文缓存 ────────┤
     L1 披露组/实体 → L2 时点图/二部消息 ───────┤
     L2 60日GRU与日批次适配器 ────────────────┤
                                               ↓
                         L3 有界残差与同编码器控制
                                               ↓
                         L4 强基线/四折/消融/统计
                                               ↓
                         L5 论文六章/答辩/投稿审查
```

一项叶任务通常以1—3个专注工作日为开发单位；全量标注/训练是单独计量的大任务，不硬塞进这个估时。具体日程见[执行日程](毕业设计周计划-2026-11至2027-02.md)。

## 五、L3：核心模型和公平对照
