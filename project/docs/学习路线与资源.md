# 毕设学习路线与资源

## 学习目标

按项目实际代码需要学习，不要求先学完金融、深度学习或大模型理论。主线是：

**数据处理 → 尾部风险标签 → 时间外基线 → 公告事件表示 → 共同持股特征 → 消融与论文写作。**

预计用 6 个阶段推进。每阶段以“能解释概念、能运行对应代码、能检查输出”为完成标准。B 站链接是检索入口，视频会更新，因此按关键词挑选播放量和近期反馈较好的课程，不把某一位 UP 主的视频作为唯一依据。

## 阶段一：Python、CSV 与 Pandas

**要会：**变量、函数、路径、字典、异常；读取 CSV/CSV.GZ；日期和股票代码清洗；连接、分组、缺失值检查；分块读取大文件。

**建议顺序：**

1. Python 官方教程的“数据结构”“文件读写”“异常”章节：  
   https://docs.python.org/zh-cn/3/tutorial/
2. Pandas 入门与 10 分钟教程：  
   https://pandas.pydata.org/docs/getting_started/intro_tutorials/
3. NumPy 快速开始：  
   https://numpy.org/doc/stable/user/quickstart.html
4. B 站搜索：  
   https://search.bilibili.com/all?keyword=Python%20Pandas%20数据分析%20入门  
   https://search.bilibili.com/all?keyword=pandas%20读取大文件%20chunksize

**项目练习：**读取一份压缩 CSV，打印行数、列名、日期范围、股票数、重复键和缺失率。不要直接把整个 RESSET Excel 文件一次性读进内存。

## 阶段二：收益、因子和尾部风险标签

**要会：**

- 简单收益率、资本收益率、超额收益率的区别；
- 市场因子、SMB、HML 的含义；
- 滚动回归、残差、历史分位数；
- 未来五个交易日窗口的构造；
- 预测日信息可得性与未来信息泄漏；
- 停牌、缺失收益、除权除息的处理。

**资料：**

1. RESSET 自带数据词典和字段计算方法，优先于字段名称猜测。
2. Kenneth French Data Library 的因子说明可作为因子模型背景资料：  
   https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html
3. Statsmodels 回归文档：  
   https://www.statsmodels.org/stable/regression.html
4. B 站搜索：  
   https://search.bilibili.com/all?keyword=Fama%20French%20三因子模型%20回归  
   https://search.bilibili.com/all?keyword=量化金融%20滚动回归%20因子模型  
   https://search.bilibili.com/all?keyword=股票%20尾部风险%20VaR%20条件风险

**项目练习：**手工检查一家公司连续 252 个有效收益和对应因子；核对回归残差；画出一段历史五日残差与滚动 P10 阈值。能解释为什么预测日 t 的阈值不包含 t 之后才完成的窗口。

## 阶段三：分类模型和样本外评估

**要会：**

- Logistic 回归与 LightGBM 的输入和输出；
- 正类稀少时的 PR-AUC / Average Precision；
- ROC-AUC、Precision、Recall、Brier 分数；
- 按年份向前滚动的训练、验证、测试；
- 边界 purge 和按交易日区块计算不确定性；
- 基线、消融和稳健性分析。

**资料：**

1. Scikit-learn 模型评估：  
   https://scikit-learn.org/stable/modules/model_evaluation.html
2. Average Precision 与精确率-召回率曲线：  
   https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html
3. LightGBM Python 文档：  
   https://lightgbm.readthedocs.io/en/stable/Python-Intro.html
4. B 站搜索：  
   https://search.bilibili.com/all?keyword=机器学习%20Logistic回归%20分类评估  
   https://search.bilibili.com/all?keyword=LightGBM%20入门%20分类  
   https://search.bilibili.com/all?keyword=PR-AUC%20不平衡分类

**项目练习：**在完全相同的时间切分和样本上比较正类率参照、Logistic 和 LightGBM。按年度输出 AP、ROC-AUC、Brier 和 Top 10% 高风险名单的命中率。不要随机打散公司日样本做主测试。

## 阶段四：公告文本与事件抽取

**要会：**

- 公告去重、公告日期对齐和时间切分；
- 结构化 JSON 抽取、提示词基线、人工标注；
- Precision、Recall、F1 和标注一致性；
- Transformer 推理；LoRA/QLoRA 的用途和资源成本。

**资料：**

1. Hugging Face NLP Course：  
   https://huggingface.co/learn/nlp-course/
2. Transformers 文档：  
   https://huggingface.co/docs/transformers/index
3. PEFT / LoRA 文档：  
   https://huggingface.co/docs/peft/index
4. Qwen 文档：  
   https://qwen.readthedocs.io/
5. B 站搜索：  
   https://search.bilibili.com/all?keyword=大模型%20信息抽取%20JSON  
   https://search.bilibili.com/all?keyword=Qwen%20LoRA%20微调%20实战  
   https://search.bilibili.com/all?keyword=大模型%20QLoRA%20微调

**项目练习：**先抽取约 300 条业绩预告，写清楚事件类别、方向和证据句的定义；比较人工结果、规则或提示词结果。标注规范稳定且确实需要时，再租 GPU 做小模型微调。发布日期没有时分秒时，保守地从下一交易日使用公告。

## 阶段五：共同机构持股数据和网络特征

**要会：**

- 报告期截止日与信息发布日期的区别；
- 公司—机构二部图与公司间共同持股关系；
- 节点度、边权重、邻居特征；
- 关系图如何按历史时点展开，避免未来持仓泄漏。

**资料：**

1. NetworkX 入门：  
   https://networkx.org/documentation/stable/tutorial.html
2. PyTorch Geometric 教程（作为扩展阅读）：  
   https://pytorch-geometric.readthedocs.io/en/latest/tutorial/
3. B 站搜索：  
   https://search.bilibili.com/all?keyword=NetworkX%20图论%20Python%20入门  
   https://search.bilibili.com/all?keyword=股权关系网络%20图神经网络  
   https://search.bilibili.com/all?keyword=GraphSAGE%20PyTorch%20Geometric

**项目练习：**先用共同机构数量、持股关系强度和邻居历史风险等少量汇总特征做消融。确认覆盖率和时点逻辑后，再学习 GraphSAGE；图神经网络不是完成主线的前置条件。

## 阶段六：实验记录与论文表达

每次实验记录：输入数据版本、标签版本、时间切分、模型参数、指标、失败原因。论文中明确报告标签公式、信息可得时间、样本过滤、缺失处理和负结果。

**完成标准：**

- 数据字段与日期范围有审计报告；
- 标签可以从输入数据重建；
- 训练/测试按时间划分且边界 purge；
- 预测结果有基线和逐步消融；
- 每张表和图能从脚本重跑；
- LLM 和图模块的实际实现与论文题目一致。

## 建议进度

| 周次 | 学习与编码重点 | 可检查的产出 |
|---|---|---|
| 第 1 周 | Python/Pandas、RESSET 字段、日期和股票代码 | 本地数据审计表 |
| 第 2 周 | 三因子、滚动回归、尾部标签、泄漏 | 标签定义说明和可重建标签 |
| 第 3 周 | Logistic、LightGBM、AP、时间外评估 | 同样本基线表 |
| 第 4—5 周 | 公告抽取规范、人工标注和提示词基线 | 事件抽取评估集与 F1 报告 |
| 第 6 周 | 股东披露时点、共同持股网络汇总 | 网络覆盖报告和增量特征 |
| 后续 | LoRA/QLoRA、GNN、稳健性、论文写作 | 有实证增益再扩展模型 |
