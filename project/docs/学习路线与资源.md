# 毕业设计学习路线与资源

学习目标不是泛泛掌握“人工智能”，而是看懂并能排查本论文的数据、标签、三路编码器、时点门控和评估代码。学习路径对应固定方案：**数据时点 → 风险标签 → 传统基线 → GRU → 公告Transformer/QLoRA → 时间图/GraphSAGE → 门控融合 → 论文复核。**

## 1. Python与数据处理

要会读CSV/CSV.GZ、处理日期和证券代码、按键连接、按公司分组计算滚动特征、分块读大文件和检查缺失/重复。

- Python教程：https://docs.python.org/zh-cn/3/tutorial/
- Pandas教程：https://pandas.pydata.org/docs/getting_started/intro_tutorials/
- NumPy教程：https://numpy.org/doc/stable/user/quickstart.html
- B站搜索： [Pandas数据分析入门](https://search.bilibili.com/all?keyword=Pandas%20数据分析入门)、[读取大文件](https://search.bilibili.com/all?keyword=pandas%20读取大文件%20chunksize)

**本项目练习：**统计每张RESSET表的主键唯一率、日期范围、缺失率，保留6位证券代码字符串。

## 2. 金融收益、三因子和尾部标签

理解日收益和超额收益、Rmrf/SMB/HML、滚动OLS、残差、经验分位数、nearest-rank、五个交易日窗口、停牌和缺失。核心是能解释为何阈值只纳入预测日前已经结束的窗口。

- Kenneth French因子说明：https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html
- Statsmodels回归：https://www.statsmodels.org/stable/regression.html
- B站搜索：[Fama-French三因子](https://search.bilibili.com/all?keyword=Fama%20French%20三因子模型%20回归)、[滚动回归和因子模型](https://search.bilibili.com/all?keyword=量化金融%20滚动回归%20因子模型)、[VaR与尾部风险](https://search.bilibili.com/all?keyword=股票%20尾部风险%20VaR%20条件风险)

**本项目练习：**手工抽查一家公司252日回归，复算一个未来五日标签，并确认未来数据只进入目标值。

## 3. 分类基线、时间外验证与统计不确定性

学习Logistic、梯度提升树、AP/PR曲线、ROC-AUC、Brier、Recall@K、扩展窗时间切分、purge和按交易日区块bootstrap。尾部标签不均衡，不能只报准确率。

- Scikit-learn模型评价：https://scikit-learn.org/stable/modules/model_evaluation.html
- AP说明：https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html
- LightGBM：https://lightgbm.readthedocs.io/en/stable/Python-Intro.html
- B站搜索：[不平衡分类PR-AUC](https://search.bilibili.com/all?keyword=PR-AUC%20不平衡分类)、[LightGBM分类入门](https://search.bilibili.com/all?keyword=LightGBM%20入门%20分类)、[时间序列交叉验证](https://search.bilibili.com/all?keyword=时间序列%20交叉验证%20金融)

**本项目练习：**使用同一批公司日分别训练Logistic、LightGBM、XGBoost，输出逐年AP、Brier和Top10%指标。

## 4. Transformer事件抽取与Qwen3 QLoRA

理解tokenizer、预训练语言模型、监督微调、JSON约束、训练/验证/独立测试、LoRA和4-bit QLoRA。公告方向不是股价方向；证据必须是原文片段。人工金标质量先于模型训练。

- Hugging Face NLP课程：https://huggingface.co/learn/nlp-course/
- Transformers：https://huggingface.co/docs/transformers/index
- PEFT：https://huggingface.co/docs/peft/index
- Qwen：https://qwen.readthedocs.io/
- B站搜索：[大模型信息抽取JSON](https://search.bilibili.com/all?keyword=大模型%20信息抽取%20JSON)、[Qwen LoRA微调](https://search.bilibili.com/all?keyword=Qwen%20LoRA%20微调%20实战)、[QLoRA原理与实战](https://search.bilibili.com/all?keyword=QLoRA%20微调%20原理)

**本项目练习：**标注约1,500条业绩预告，至少20%双标；方向类别、原因和证据单独评估。Qwen3-8B QLoRA输出结构化公告事件，另设按时间留出的人工测试集。

## 5. 时间图、GraphSAGE与机构关系

理解公司—机构二部图、图节点和加权边、邻居采样、消息聚合、公司—机构—公司两跳关系、图快照以及时间边。先掌握`InfoPubDt`和报告截止日的差别，再学图网络。

- NetworkX教程：https://networkx.org/documentation/stable/tutorial.html
- PyTorch Geometric教程：https://pytorch-geometric.readthedocs.io/en/latest/tutorial.html
- Hamilton et al., GraphSAGE：https://arxiv.org/abs/1706.02216
- B站搜索：[NetworkX图论Python](https://search.bilibili.com/all?keyword=NetworkX%20图论%20Python%20入门)、[GraphSAGE原理](https://search.bilibili.com/all?keyword=GraphSAGE%20图神经网络%20原理)、[PyTorch Geometric](https://search.bilibili.com/all?keyword=PyTorch%20Geometric%20GraphSAGE)

**本项目练习：**每个预测日只构建此前公开的股东边；按公司/机构报告覆盖率、孤立节点和披露年龄分布。GraphSAGE不使用邻居未来标签。

## 6. GRU、可用性感知门控和模型解释

掌握序列张量、隐藏状态、GRU、掩码、未加权二元交叉熵、辅助损失、早停和随机种子。重点理解年龄有界残差公式及其上界性质；两辅助分支缺失时必须严格回到序列预测。

- PyTorch教程：https://pytorch.org/tutorials/
- PyTorch GRU：https://pytorch.org/docs/stable/generated/torch.nn.GRU.html
- B站搜索：[PyTorch GRU](https://search.bilibili.com/all?keyword=PyTorch%20GRU%20时序预测)、[多模态门控融合](https://search.bilibili.com/all?keyword=多模态%20门控融合%20神经网络)、[图神经网络分类](https://search.bilibili.com/all?keyword=GraphSAGE%20节点分类%20PyTorch)

**本项目练习：**逐一比较GRU、GRU+公告、GRU+图、简单拼接、固定权重和可用性感知门控，并用门控输入消融解释收益来自哪里。
