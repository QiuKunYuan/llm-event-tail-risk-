现有数据足以支撑题目和全套模型主线。**不需要为了开题先去下载市值、换手率或财务报表**。未核实字段不得补写成现有特征；研究范围以收益/因子、公告、股东图为主。

## 建模前必须完成的数据核验

1. 将原始表文件名、导出日期、字段映射、主键、日期范围、缺失和重复规则写入版本化数据字典。
2. 按预测时点核对公告发布日期/发布时间。没有可靠时分秒的公告从公告日后的下一交易日生效。
3. 按 `InfoPubDt` 建立股东记录版本；报告期截止日不能替代实际公开日。处理流通股东/总股东重复口径。
4. 机构实体以 GDID 为首选。GDID 缺失的机构用类型和规范化名称建候选映射，人工抽查后定版；自然人不进入机构关系图。
5. 报告机构映射成功率、公司图覆盖、孤立率、边数和持股信息年龄分布。图覆盖低的公司日不隐去；全样本与共同覆盖样本均须比较。
6. 标签未来窗口缺失不填充。保留预测日 ID 与目标区间，统一向各模型提供相同训练/验证/测试公司日。

## 当前不可用或不进入模型的字段

- 本地所谓 DTURNR 工作簿只有代码和日期列，没有换手率数值。
- 尚无经字段审计确认的全时期成交量、成交额、日市值和可按公告发布日期对齐的财报特征。
- 模型不使用这些字段；波动率由现有收益历史计算。
- 三因子有未来实现值时，该值只参与事后标签生成，不能作为同日预测特征。

## 已知样本边界

DRET 当前止于 2024-07-31，已生成标签止于 2024-07-24；2024 测试折是部分年度。首轮基线测试总计约 337.2 万个公司日。该数据范围需在图和公告的交集样本再审计一次，不能因交集筛选变化而声称测试条件不变。
