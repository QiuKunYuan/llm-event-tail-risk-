# Qwen3-8B 业绩预告事件抽取训练说明

> 该微调任务是论文固定模型链路的一部分。Qwen只抽取公告语义，不直接预测股票收益。正式训练必须使用人工裁决标签，模型自生成结果不能充当金标准。

## 任务定义

输入：RESSET 业绩预告正文。输出严格JSON：

```json
{
  "direction": "改善|恶化|基本稳定|混合|不明确",
  "causes": ["公告明确陈述的原因"],
  "evidence": ["公告正文中的原文证据片段"]
}
```

方向描述预计经营/财务业绩，不代表股价涨跌。RESSET已有的预测类型、幅度区间和数值保留为结构化输入，不由模型猜测。诉讼仲裁采用独立的公告类型、发生数和最近公开年龄特征，不混入业绩方向分类。

## 标注规模、时间切分和质量

当前 `prepare_announcement_annotations.py` 的默认规模为1,500条业绩预告主标注和300条双标样本。先从2017—2019训练年份中取200条试标，修订并冻结规范后再完成全部标注。按年份和RESSET预测类型分层；保持预设时间切分：2017—2019训练、2020验证、2021—2024-07独立测试。这个截止点保证事件抽取器不使用首个风险预测测试期之后的人工标签。相同事件及修订记录不得跨集合。

标注说明见 [`公告人工标注规范-v1.md`](公告人工标注规范-v1.md)。报告方向标签一致率与Cohen's Kappa、分字段错误案例、证据在原文中的命中率。至少20%由第二人独立标注；先独立后对照，裁决标签回写主标注文件。证据必须逐字来自正文，原因不得从常识推断。

抽样在授权 RESSET 数据目录运行：

```bash
python3 project/scripts/prepare_announcement_annotations.py \
  --sample-size 1500 \
  --double-size 300 \
  --seed 20261123
```

输出文件名含实际样本数，位于 `project/outputs/annotations/`，该目录含公告正文并被Git忽略，不能提交。

## 构造 SFT 数据

裁决完成后运行：

```bash
python3 project/scripts/build_sft_dataset.py \
  --input project/outputs/annotations/earnings_annotations_1500_annotator_a.csv \
  --output-dir project/outputs/sft_dataset
```

程序按预先分配的时间字段输出 `train.jsonl`、`validation.jsonl`、`test.jsonl`，检查方向枚举、合法JSON、证据是否出现在公告正文、事件ID唯一性及待裁决行。任何划分不满足预期年代比例都应先检查抽样及公告覆盖，不能随机打散时间序列以扩大训练集。

## 在租用 GPU 上做 QLoRA

当前项目环境没有可见 GPU，训练安排在用户租用的单卡环境。Qwen3-8B 使用4-bit量化和梯度检查点；建议选择24GB或以上显存并先用少量样本确认峰值占用。先复制代码和人工标注文件，避免把受限公告全文同步到公开仓库。按GPU的CUDA版本安装PyTorch，再安装项目中的 `requirements-qlora.txt`。

```bash
python project/scripts/train_qlora.py \
  --train project/outputs/sft_dataset/train.jsonl \
  --validation project/outputs/sft_dataset/validation.jsonl \
  --test project/outputs/sft_dataset/test.jsonl \
  --model Qwen/Qwen3-8B \
  --output-dir project/outputs/qwen3-8b-qlora \
  --max-length 2048 \
  --epochs 3 \
  --batch-size 1 \
  --gradient-accumulation 8 \
  --lora-rank 16 \
  --lora-alpha 32 \
  --compute-dtype bf16
```

显卡不支持 bfloat16 时使用 `--compute-dtype fp16`。若显存不足，先将 `--max-length` 调到1024并保持 batch size 1，不应删测试样本。训练日志保存基座模型版本、配置、显存、耗时、样本量、每个epoch训练/验证loss和最佳adapter。

模型生成评估：

```bash
python project/scripts/evaluate_event_extractor.py \
  --data project/outputs/sft_dataset/test.jsonl \
  --model Qwen/Qwen3-8B \
  --adapter project/outputs/qwen3-8b-qlora/best_adapter \
  --output-dir project/outputs/event_extractor_eval \
  --compute-dtype bf16
```

独立测试集报告JSON合法率、方向准确率和macro-F1、原因/证据匹配及证据原文命中。只报告loss下降不够；抽取指标必须与人工金标比较。

## 事件表示进入风险模型

对经过独立质量评估的微调模型，在业绩预告正文上缓存最后层池化表示和结构化方向/原因/证据特征；报告原始文本不写入公开Git。按真实 `publication_date` 生效；只有日期而没有时分秒时，从下一交易日起用。每个公司日汇总近20个交易日的预告表示。公告缺失状态单独送入门控。

模型验证包含两层：一是抽取器对独立人工测试集的字段级表现；二是固定预测折、同样本下加入事件表示前后的风险AP差。前一层高分不意味着后一层一定提高。
