## 2. GPU启动与长度口径

单卡起始24GiB；先测200训练样本的显存与吞吐再排租赁。只向已授权的训练环境复制数据，不将正文同步到公开GitHub。

初始配置：4bit NF4/双重量化，LoRA rank16/alpha32/dropout0.05，batch1，梯度累计16，3epoch，学习率2e-4，gradient checkpointing。

`--max-length 2048`表示完整system+user+assistant训练序列上限，不是正文长度。正文预算起始1024token，剩余预算留给提示和JSON；正文截断及证据位置需要在数据准备中统一实现和记录。当前脚本对总长超限整条跳过，不会自动智能截断正文。必须报告训练/验证/测试长度跳过数及类别；零样本与QLoRA比较采用相同输入/有效评价集，并补报长文本未覆盖率，不能为提高结果删难例。

```bash
python3 project/scripts/train_qlora.py \
  --train /path/private/sft_dataset/train.jsonl \
  --validation /path/private/sft_dataset/validation.jsonl \
  --model Qwen/Qwen3-8B \
  --output-dir /path/private/qwen3-8b-qlora \
  --max-length 2048 --epochs 3 --batch-size 1 \
  --gradient-accumulation 16 --lora-rank 16 --lora-alpha 32 \
  --compute-dtype bf16
```

BF16不支持时用FP16；记录具体基座revision、GPU、CUDA、依赖冻结、训练配置、最佳验证模型、耗时/显存与长度跳过。输出须放仓库外。上面不把独立测试传入训练过程；最终抽取评价再读取它。

## 4. 缓存与风险输入

这一段对应待开发的正文缓存程序，不能用上述生成评价脚本冒充已经实现。

- 模型冻结后，对去重事件编码一次；只取最后一层正文token掩码均值，不含系统、包装、padding或生成JSON。
- 保存原文哈希、模型/adapter/tokenizer版本、模板、正文范围和截断策略；版本改变即失效。
- 缓存原始向量与预测字段，风险训练时学习事件投影；不缓存随机GRU/图表示。
- 公司日只取已经生效的近60个市场交易日事件，最多8条；日期级公开从下一交易日起有效。
- schema/证据支持给质量标记，不用模型自报置信度当概率；无公告与抽取失败分别统计。
- 诉讼独立形成5/20/60日类型计数和年龄，不能被业绩预告掩码屏蔽。
- 测试风险特征只用预测字段，不读测试人工标签。

现代Qwen的预训练晚于历史区间，本实验是回顾性研究。匿名文本和原生字段对照有帮助，但不能保证不存在预训练记忆。
