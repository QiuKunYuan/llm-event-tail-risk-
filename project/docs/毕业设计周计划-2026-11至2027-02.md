# 毕业设计周计划（2026-11 至 2027-02）

> 计划基准日：2026-11-10  
> 硬节点：2026-11-27 前完成开题报告；2027-02-28 前形成完整、可提交的毕业设计报告。为避免把写作挤到最后，目标是在 **2027-02-07 前完成报告初稿**，2 月下旬用于导师反馈、修订和核对。  
> 当前执行方案：预测 A 股上市公司未来 5 个交易日自身的条件异常下跌风险；不把公司间因果风险传染作为研究结论。主线按“标签与量价基线 → 公告信息 → 共同机构持股信息 → 消融和稳健性”推进。

## 一、先固定交付范围

### 必须完成的主线

1. 明确研究问题、风险标签和无泄漏的时间切分。
2. 形成可复现的标签面板和量价特征。
3. 跑通 Logistic 回归与 LightGBM 基线，并用相同样本、相同切分比较后续信息增益。
4. 加入至少一种公告特征和一种共同持股关系特征；若某一模块因数据或时间受阻，报告中说明并把结果降为扩展分析。
5. 完成时间外评估、消融/稳健性分析、结果解释和论文初稿。

### 作为扩展、不作为按期交稿前提

- Qwen 模型微调（LoRA/QLoRA）。先尝试规则或提示抽取及小样本人工核验；只有标注质量、算力和时间都允许时再微调。
- GRU、GraphSAGE、门控深度融合。先用传统预测器和可解释的邻居汇总特征验证信息增益；主线结果不依赖深度图模型。
- 财务指标、日市值、违规处罚等未确认已下载的数据。它们不是当前主线的硬依赖。

## 三、关键依赖和并行关系

```text
开题报告（11/27 截止） ──────────────┐
                                      ├─> 数据/标签口径冻结 ─> 基线 ─> 信息增量 ─> 稳健性 ─> 报告
行情及收益补齐（可延迟，12 月并行） ─┘                    公告特征 ─┤
                                                               持股特征 ─┘
```

- **开题不等于所有数据已齐。** 开题要准确报告已拥有的数据和缺口，研究方法写清楚可行方案与备用口径。
- **标签和切分先于复杂模型。** 标签定义、因子冻结、阈值历史窗口和 purge 规则不冻结，后续模型比较没有可比性。
- **公告和股东模块并行开发。** 两者都以已冻结的标签面板和时间切分为基础，不相互等待。
- **写作与实验并行。** 12 月开始写数据与方法章节；1 月填结果；2 月不从空白文档开始。

## 四、延期时的决策规则

### 数据下载延迟

若 2026-12-13 前日行情仍未全部到齐：以已核实的 2015-01 至 2024-07 个股收益及因子数据建立主样本，收窄并如实报告样本期；已下载的行情字段只在覆盖完整且口径核实后加入。不要把文件名所示覆盖期当成真实覆盖期，也不要用当前上市公司列表筛掉退市样本。

### LLM 标注或微调延迟

先用 RESSET 原生公告字段、规则/词典特征和小规模提示抽取完成公告对照；若标注一致性或下游效果不稳，报告中把 LLM 微调列为后续工作。LLM 不能代替基线，也不能作为论文按时完成的单点依赖。

### 股东图效果或覆盖率不理想

先报告覆盖率和时点特征，再比较少量共同持股汇总特征；若图很稀疏或缺失严重，就把股东模块作为探索性结果，主结论仍由量价基线及公告增量支撑。GraphSAGE 不作为必做项。

### 整体进度落后一周以上

按以下顺序删减：深度网络/QLoRA → 复杂图构造 → 非核心稳健性；保留标签审计、时间外基线、至少一组增量比较、核心稳健性和完整论文。不要通过省略时间外评估或泄漏检查来赶进度。

## 五、每周固定检查清单

- 本周是否有可检查的文件、数据表、图或结果，而不只是“看过资料”？
- 新增变量是否在预测时点已经公开？公告、财报和股东数据是否按信息发布日期对齐？
- 训练/验证/测试是否按时间划分，交界处是否 purge 至少 5 个交易日？
- 比较模型是否使用相同样本和相同标签？是否报告了样本数及正类率？
- 结果、代码、参数和数据版本是否留下记录？
- 本周任务若未完成，是否已经触发上面的降级规则，而不是继续挤占写作时间？
