## 2. 关键路径和并行工作

主关键路径：**股东完整组/版本核验 → 图流和共享日批次 → 固定对照 → 全矩阵训练 → 统计/结果章**。

另一条汇合路径：**200试标 → 1500裁决/300双标 → Qwen验证选模 → 冻结正文缓存 → 共享日批次**。

2026-11-24已提前完成全量标签重建、20公司独立参照、市场日历和四折共享索引读回验收；不再将这部分列为未开始。证券主体映射、股东完整组/版本及真实日装配器仍未放行。仅收益基线、论文现状/方法章可与人工标注并行，不应等GPU租用才开始。普通门控/MSGCA式适配可先用合成批次开发，但合成结果不能进入金融结果表。

## 3. 用实测工时修订排期

人工约1800次判定加裁决，试标已计入1500。若5分钟/条，仅判定就150人时；争议与复核另加。这个数是预算示例，不是已测工时。12/06前用试标记录真实分钟/条，判断能否在12/13前完成；若不够，应分配更多人工时间，而不是偷偷以模型生成替代金标。

约420次锁定配置的神经/P5运行，另有神经验证选参（第二学习率最多额外84次）、最多192树配置候选、60次同信息树模型种子复训上限及Qwen训练/多版缓存。12/20前必须实测代表性公司日的训练/验证/IO时长、峰值显存和边数。按各运行实际训练日数/早停轮数求和，再加30%重跑与资源余量。没有GPU实测不能声称几小时就能跑完。
