# 业绩预告人工标注规范

修订：2026-11-24。沿用文件名，操作格式版本为 `annotation-workbench-v1`。新手直接看[操作指南](../../docs/数据准备/数据补证与人工标注操作指南.md)。本规范在200条训练试标后冻结；独立测试不能用来修改字段、提示或规则。

## 1. 标什么，不标什么

只依据提供的 `forecast_text`，标注公告表达的**经营/财务业绩方向、明确原因、原文证据**。不预测股价，不判断尾部事件，不找后来实际业绩，不查行业背景来补原因。诉讼不使用这套方向标签，只作为独立结构控制。

模型目标保持三个字段，不新增原因分类或经营/财务两个方向：

```json
{"direction":"改善","causes":["明确原因的简洁短语"],"evidence":["正文原话"]}
```

用户在Excel填中文格，不手写JSON。`causes`是自由短语数组，不是分类代码；`evidence`是字符串数组，不是嵌套对象。行政状态、置信度和耗时不进入模型目标。

## 2. 方向：五选一

| 值 | 判定 | 常见误区 |
|---|---|---|
| 改善 | 利润/收入上升、亏损收窄、扭亏或明确经营改善 | 仍然亏损也可能改善 |
| 恶化 | 利润/收入下降、亏损扩大或明确经营恶化 | 仍然盈利也可能恶化 |
| 基本稳定 | 明确预计与同期基本持平，且无更强的相反方向 | 不能因为看不懂就选稳定 |
| 混合 | 明确存在方向相反且均重要的表现 | 多个指标不自动等于混合 |
| 不明确 | 已阅读，但比较基期或信息不足，无法判断方向 | 没说原因不等于方向不明确；未读完留作未完成 |

优先看公告对当前预测期的主要结论，用明确数字辅助，不能未经词典解释 `forecast_object` 等原码。只有绝对盈利数值却没有基期/方向词，无法从正文判断变化时选不明确并写疑问；预测区间跨不同方向、多个报告期难以确定主体时待讨论，不能凭区间中点猜。

## 3. 原因与证据

- 有明确原因：原因状态选“已说明”，每行一条短语（Excel内Alt+Enter换行）。可简洁概括，但不得把业绩结果改写成原因。
- 无明确原因：选“未提及”，原因格留空，转换为 `[]`；方向仍按正文正常判断。
- 原因有歧义：选“待讨论”，写明疑问；不以空格静默表示已确认无原因。
- 证据填1—3段，从正文逐字复制到证据1/2/3；支持方向或原因，不改写，不补省略号，不引用数据库元数据。
- 只统一CRLF/LF换行编码，不通过删除全部空白接受改写。原文命中只是程序检查；每个原因是否真的受支持、方向是否正确仍由人工复核。
- 方向不明确也应复制能体现信息不足的原文。不用空证据代替阅读；正文为空的记录不应进入本包。

## 4. Excel填写与状态

工作表“待标注”中A/B和M—R列为来源，不能改；C—L为填写区：方向、原因状态、原因短语、证据1/2/3、置信度、填写状态、疑问、可选耗时秒。正文完整存储，显示不全时看编辑栏/调整行高，不能自行截断正文。

- **未完成**：尚未读/填完，不是一个标签。
- **已填写**：已经给出三个字段的草稿；不代表训练金标已放行。
- **待讨论**：低置信度、文本疑似截断、比较期不清等，必须写疑问。
- 置信度只选高/中/低，是人工自评，不是校准概率。低置信度须复核。
- 耗时可空，填时用非负有限秒数，用于估计人工工时，不能从CPU/GPU时间反推。

程序导入后生成待修复清单，不替人判语义。草稿、待讨论、未批准和未知状态禁止进入SFT；正式转换要求显式人工复核人、accepted状态和no待裁决。保留所有独立原稿及裁决说明。

## 5. 锁定样本与独立双标

主包1500=训练800（2017—2019）/验证200（2020）/测试500（2021—2024-07）。200试标是训练800子集；300双标是1500子集，其中训练152/验证40/测试108。

| 阶段 | A | B |
|---|---:|---:|
| 训练试标 | 已选200 | 与已选300双标重合的42 |
| 规范冻结后 | 剩余1300 | 剩余258 |

B独立阅读，不能看A答案或裁决稿。42条只作训练期试标一致性检查，不代替最终300条。先按独立原稿计算方向一致率、Kappa和原因/证据差异，再讨论与裁决。短语或引文不同不自动表示语义错误；退化单一类别下Kappa可能无定义，不能写成1。

试标按record_id回写对应主样本；200与1300合成1500，42与258合成300，不把200额外拼成1700。当前最终包没有跨集合家族或规范化正文重叠；这不证明原始披露版本完整。测试金标只能评价，不参与训练、提示词选择、规范修改或调参。

## 6. 虚构练习（不是实际样本金标）

1. “预计净利润同比增长30%，主要由于产品销量增加。”：改善；原因“产品销量增加”；证据复制原句。
2. “预计净利润800万元，上年同期1000万元，下降主要由于原材料成本上升。”：恶化；原因“原材料成本上升”；不能因仍盈利选改善。
3. “预计亏损300万元，上年同期亏损1000万元。”：改善；原因未提及；复制比较句。亏损收窄不等于已扭亏。
4. “预计本期业绩与上年同期基本持平。”：基本稳定；原因未提及。
5. “预计营业收入明显增长，但净利润同比下降，主要由于成本上涨。”：两个明确且重要的反向表现，混合；原因“成本上涨”。
6. “预计净利润为800万元。”：正文无比较基期或方向词，不明确；原因未提及，注明缺少比较信息。

练习只解释规则，不预填任何真实公告答案，不计算金融预测结果。
